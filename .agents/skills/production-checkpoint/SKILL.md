# 制作检查点

第二作的返工多数不是因为缺少经验，而是做决定的那一刻没有用上已有经验（见[第二作复盘](../../../works/0002-zaporozhian-reply/delivery/retrospective-2026-10-29.md)）。本 Skill 只负责在那一刻把人带到正确位置并留下结论。检查问题和案例只维护在[制作经验入口](../../../docs/production-lessons.md)和作品复盘里，这里不复制。

## 1. 判断时机

| 正在做什么 | 时机（制作经验入口表格中的行） |
| --- | --- |
| 新会话、“继续”、读到 current 或旧状态文件 | 续接作品 |
| 设计段落、改故事因果；牺牲、救援、逃离、群戏、回画 | 确定故事与难场面 |
| 写完或改了生成正文；裁图、选参考；准备上传、核价或申请授权 | 本地冻结输入、随后按授权准备执行 |
| 生成或下载完成，要用末帧、末态或动作接下一段 | 生成完成、启动后继前 |
| 片段接入工作片；创作者再次指出同类问题 | 接入工作片、反馈重复时 |
| 字幕、信件、片尾资料、增强、标题描述、发布 | 完整候选与发布准备 |

同时命中几个时机，就各读对应行，合并成一次结论。是否“同类问题”按[问题表](../../../templates/work/production/problem-ledger.csv)的稳定问题ID和症状判断，不看措辞是否相同。

简单镜头只做该时机里与它相关的一两项（例如换一张参考图，上传前的离线文件检查仍要做），不另开研究、方案比较或审批。调用后发现并不涉及制作决定，写一句“检查点：不适用”和原因即可。

## 2. 只读需要的部分

1. 在制作经验入口只读该时机那一行：三个问题和“最小留下什么”。
2. 打开该行列出的案例，先读“最小依据”：当时的输入、出错表现、怎么改的。对照现在的材料判断是否同类；不同类就写明哪个条件不一样，不硬套。
3. 续接和付费准备另读[当前执行平台](../../../docs/execution-platform.md)。本机装了什么技能、历史文件名、旧授权都不是执行依据。

不通读 `docs/history/` 或整篇复盘。

## 3. 用当前材料回答，不复述规则

三个问题都要落到具体对象：哪份正文、哪张图、哪个时码、哪句反馈。下面几处是第二作反复漏掉的，命中时必须做到：

- **冻结正文**：先不看解释，像普通读者一样复读最终正文，说出谁对谁做什么；再按字面模拟全部约束，问“演员完全照做，主行动还会发生吗”。剪辑理由不进模型输入。
- **上传素材前**：对最终文件做执行平台列出的离线检查（宽高比、尺寸等）。不合格先改，不带着已知问题申请授权。
- **同类反馈第二次出现**：先判断问题在事件、机位、动作、观看顺序还是剪点，写出原假设、新证据、这次改什么、预计看到什么。写不出来就停止付费重试，改为提出两三种实质不同的处理或剪辑方案，请创作者选。
- **生成完成后**：先看主行动、受力来源和人物反应是否成立，再用它的末态启动下一段。技术成功另记。
- **发布前**：按真实时间轴核对标题和描述的承诺；史实、传说、虚构分开写。

同样要守住经验的边界，不把它扩大成新规则：

- 执行平台里的入口条件只对记录的平台、模式和日期成立。换了模式、平台或时间较久，写明“未核实”，交给当前核价确认；满足这些条件也不等于素材一定会被接受。
- 每个案例写有自己的不适用边界，例如 L03 允许必要的沉默和静态原画尾声，L04 不要求每个镜头都运镜。结论不越过这些边界。
- 文件是否存在、解码、ASR、响度、指纹只能证明技术层面；速度感、表演、听感和可读性要靠正常速度观看。没看过、没听过就写“未验”，不写“通过”。

## 4. 留下结论

- 回复创作者时，在行动前写一行：`检查点：<时机>｜相关：<案例ID或“无”>｜结论：<一句话>`，让创作者能看到这次检查有没有发生。
- 在作品制作卡或问题表追加制作经验入口“每轮只记录一个短结论”的格式，不另建文件。
- 结论涉及主题、人物动机、结局、新的付费或外部操作时，停下来合并成一次提问；其余由 Codex 直接完成。

## 5. 出现新经验时

按制作经验入口的“新经验”格式写进作品复盘，附最小依据（原词或原话、出错表现、修改结果）。只有新增条件或反例才改入口表，并链接到新案例。修改本 Skill、入口表或案例后，按[评测](evals.md)比较改前改后，结果记在评测页末尾。

## 边界

本 Skill 不产生授权，也不替代创作者观看与定稿。每次付费仍需创作者明确授权和积分上限，见 [AGENTS.md](../../../AGENTS.md)。
