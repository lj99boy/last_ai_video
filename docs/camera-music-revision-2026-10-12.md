# 从“展示会动的画”到“进入一个活着的夜晚”

2026-10-12，针对首作完整审看片反馈。以下区分实片诊断、来源事实、本片推导，不把阅读 Skill 当成调用或验证成功。

## 实际失败在哪里

- 原剪辑20.0–24.5秒是S004a：固定机位，前1秒视线，1–3秒右手松披肩、下落约10cm，结尾再次停住。微动作占据4.5秒却没有相应信息量，观众感到定格。
- S003执行提示词明确写了 `Camera stays fixed` 和 `Last 2 seconds still poised`。这与运镜方案中的后退跟随不一致。不能只检查方案写得好不好，必须核对最终提交给模型的文本、参考帧几何和实际输出。
- 生成5秒是素材长度，不是必须使用5秒；连续把“动作完成后停稳”剪进去，就会形成逐张展示的节奏。
- 原渲染脚本直接concat各镜，没有逐个接点设计。S008末尾同伴挡住女主；20秒从全身直切相似角度中景；24.5秒女主从左侧跳到右侧、看向改变，同伴和餐厅布局也变化；29.5秒后还有AI正视图向原照片的外观过渡。
- 只有最终回画需要动作真正凝固。中途可以有短暂静镜，但须有足够的行为或情绪信息；不是要求全片所有镜头不停运动。

## 重新阅读的第一手材料

1. [Simon Duggan谈《了不起的盖茨比》摄影](https://britishcinematographer.co.uk/simon-duggan-acs-the-great-gatsby/)。检索可读的采访摘录明确谈到当时的新鲜、现代感，反对默认把年代片拍成旧布景、静态机位。全文直接打开本次超时；不据此虚构未读部分。
2. [Simon Duggan本人访谈](https://www.closelyobservedframes.com/post/an-interview-with-simon-duggan)。已读：派对段用斯坦尼康和伸缩摇臂穿行于人群，依靠时间、调度与表演；漂亮长镜头仍可能因剪辑节奏被剪掉。**本片推导**：从侍者带领观看、女主引领摄影机，保留前中后景视差；不照搬狂欢规模、纸屑或1920年代服饰。
3. [Seamus McGarvey谈《安娜·卡列尼娜》](https://www.pushing-pixels.org/2013/10/03/the-fine-art-of-cinematography-interview-with-seamus-mcgarvey.html)。已读：摄影机与演员动作一起规划，移动时光线也随场面调度；复杂运动来自事先分镜。**本片推导**：银裙的亮度变化由人物穿过光区产生，摄影机持续承接动作；不复制舞蹈、冻结群众或人物剧情。
4. [Focus Features制作介绍](https://www.focusfeatures.com/article/all_the_stage_is_a_world?film=anna_karenina)：空间设计应帮助情绪与人物关系，不能只做建筑展示。**本片推导**：窗外镜头要预告来者和门的位置；若只是孤立漂亮夜景，就应缩短或重建连接。

## 可复用执行原则

1. **参考职责要分开**：原画控制服饰、胸花和头部造型；风格图控制笔触；当前分镜控制动作姿态；不把旧生成图升级为原作依据。
2. **按相邻两镜设计**：同时列前镜离开动作、后镜进入动作、人物画面位置、运动方向、光区与环境声连接；每镜漂亮不能保证连贯。
3. **运动必须有实际视差**：前景经过、中景人物和后景建筑相对变化；全图缩放不能冒充跟拍。
4. **裁掉等待，不删掉呼吸**：留白由新信息和情绪决定；不能机械追求固定秒数，也不能把所有静镜判坏。
5. **回画的空间先成立**：女主、同伴、侍者与桌子先落在可接原作的位置，再凝固、后退；不能用首尾帧变脸换帽完成叙事。
6. **配乐改变结构**：先选实际乐句，再安排亮相、转折、回墙。主题仍是传统餐厅里摩登女郎进入；落寞来自观众意识到美好夜晚已经远去，不要求女主突然悲伤。
