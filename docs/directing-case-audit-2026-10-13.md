# 原片、LibTV 实例与 Skill 核查

2026-10-13。针对用户指出的僵硬、缺乏灵动、已花费数百元而效果不足。本轮只做公开页面、现有文件与本地记录分析，没有提交图片或视频生成，没有安装新技能，没有充值。

## 结论与证据边界

找到了有成片播放器、有公开制作回放的 LibTV 案例；也找到了导演分析类 Skill。但本轮没有找到能证明“同类油画人物、薄银裙、双人舞、低重试成本”均稳定成立的现成方案。不能用 Skill 名称、使用人数或一次优秀展示推算成功率。

远程视频通过浏览器播放器播放、暂停、定位并观察若干画面。本轮的时间点是媒体定位位置，不是逐帧测定的剪辑边界；没有实际听辨音轨，也不把分散截图称为完整动态验收。ARKE 视频的独立媒体地址被 Chrome 拦截，未绕过或下载；其分镜与制作阶段证据来自正常可读的创作回放。

## 1. 用户原始参考片：先发生事情，再形成画中姿态

[仕庄 ShiZhuang《列宾画里最自由的一对恋人》](https://www.xiaohongshu.com/explore/6ab3cf5a0000000012035c3e)。通过原任务中用户提供的分享链接打开；公开仓库不保存分享鉴权参数。播放器时长约31.15秒。作者页面标注 AI 内容并带有 Seko 标签；这不能证明具体模型、生成次数和成本。

结合[前次重看](reference-repin-rewatch-2026-10-13.md)，本轮补充核对：

| 定位时间 | 可见画面 | 可迁移的导演判断（分析，不是作者自述） |
| --- | --- | --- |
| 开头 | 低处跑动脚步、摆动衣服、前后两人 | 已经在做事，观众被带进运动；不以人物站稳展示为起点 |
| 2.0秒 | 女子靠近镜头的脸，画面带运动模糊 | 由身体行动切到参与者的情绪；不强求所有时刻全身、五官都完美静止 |
| 4.5秒 | 侧向双人全身，男子往浪里走，女子跟来 | 交代前后距离、行动目标和环境阻力；全身镜有行动职责 |
| 6.1秒附近 | 女子帽肩在近处，男子在海里回身张臂 | 前景遮挡保留关系，景深改变注意对象；不是孤立漂亮肖像 |
| 12.1秒附近 | 男子向女子伸出手，中景同框 | 把邀请落实成可以回应的动作 |
| 13.6秒附近 | 双手接触近景 | 情绪发生变化的动作值得切近；不是为了凑景别 |
| 15.9秒附近 | 两人牵手迎着浪走来，衣摆、水花一起变化 | 环境参与表演，服装运动有脚步与外力原因 |
| 17.9秒附近 | 女子缩肩、笑，男子在边缘可见 | 她对刚发生的事有身体反应，面部镜承接全身动作 |
| 末尾 | 回到绘画局部与全画 | 前面的经历为最终姿态提供前因 |

我们借鉴行动、反应、接镜与画作落点的关系，不改用它的爱情主题，不据此擅自缩短本片开场。原作者的文案解读也不作为画作史实。

## 2. LibTV Skill Hub：逐项核查，而非照名选用

入口：[LibTV Skill Hub](https://www.liblib.tv/skill)。社区作者发布，不等同于平台对导演水平背书。

### 高奢感TVC / 大葱同学

标识：`luxury-brand-tvc-creator-8db3e80ed29a49109eb6c801f13bb76c`。

详情有三个示例播放器。本轮实际检查了第三个约15.07秒香水示例：开头海岸环境，约3.98秒产品近景，约8.19秒人物半身侧向，约11.78秒人物持瓶贴近面部，末尾人物与产品同框。可借鉴环境—材质—人物—关系的景别分工，但不足以证明复杂舞步与服装运动能力。

最有用的新证据是第一个 ARKE 广告的[公开创作回放](https://www.liblib.tv/canvas/chat-share?shareId=K0tlxNnRvu&sourceSkillTemplateUuid=3582694128aa455cbcf7a65b7a7a4d2c)：

- 先确定30秒、16:9、品牌形象、视觉基调；准备场景氛围、产品三视图与细节图。
- 前15秒的计划包含隧道远景、高架追拍、侧面平行、车灯近景、轮毂微距五种观看方式。
- 后15秒规划俯拍、环绕、尾灯、正面与品牌收尾。
- 公开回放展示前后两个15秒视频节点，再与音轨合成；前段得到该案例用户认可后才生成后段。

**可以借鉴：分镜数量与生成任务数量分开设计。** 不能把“减少测试重试”误译为“减少镜头”。也不能反向承诺本片只要两次就成功：该案例没有披露完整失败记录、准确扣费、模型参数与重复运行历史，汽车的刚体运动不等于双人握持和薄裙动态。

### POP MV / 鱿鱼chill

标识：`pop-music-video-beda8103d1a8414aa15aa0eb1db95a07`。播放器约62秒；查看了开头、约9.93、19.75、29.66、41.78、53.73秒。

同一粉色造型人物，画面从夜街全身，变为甩发近景、远景，继而室内背面全身、面部特写、屋顶中景。可以直接确认“以一个人为中心”不要求“始终正面、始终全身”；造型相同而观看距离、朝向、动作阶段改变。

详情仅提供简介、输入输出与示例，没有拿到完整 Skill 正文、生成过程和成本。不能将其列为已验证的省钱生产流程。现代唱跳、甩发、换场景也不是本片要照抄的动作。

标识：`fashion-brand-tvc-director-ef77fa37cc044640a7aadddfe3022cb9`。本轮重新读取完整 SKILL.md。

有服装和人物一致性、前景、动作接镜等可用要求；但固定20秒、四个约5秒镜头，禁止舞蹈，以慢走、轻转、微表情为主，还允许用慢放与定格补救。与本片明确的舞蹈、灵动和自然原速要求不匹配，不采用整套模板。界面第一个示例播放器显示34秒，已经与正文20秒硬限制不同，进一步说明不能只依据说明书认定模板得到严格验证。

## 4. 本项目真正应纠正的错误

证据：[S013T实际提交文本](../works/0001-in-london/production/film-v06/S013T-motion.txt)，以及[10月12日已记录的问题](camera-music-revision-2026-10-12.md)。

1. **方案与提交文本脱节。** 以前已经发现 `Camera stays fixed` 与计划跟拍矛盾，这次又用“男伴不得重新入画、女主始终完整、只转小弧、结尾收住”把舞蹈限制成窄空间的姿态变化。既有研究没有贯彻到执行，不是再查一遍术语就算解决。
2. **把形象参考当作每镜构图模板。** 已认可双人图负责身份与气质，不代表每镜都要从漂亮、站稳、面对镜头的姿态开始。动作中的起态和终态需要服从相邻镜头。
3. **把视觉主角误当作唯一完整人物。** 男伴可正常参与舞步；由女主发起、摄影机随她、关键表情停在她身上建立主次。只留画外手会让她像被牵着，削弱主动性。
4. **每条都拍成可以独立结束的小片。** 多次收步、停稳再切下一镜，使全片不断重新开始。素材时长不等于剪辑时长，切点应承接正在发生的动作。
5. **布料没有被行动证明。** 轻薄和碎闪不能只靠形容词；同一转身内应看见腿部带动、后摆跟随、转速改变后的回落，以及经过不同光区时碎闪移动。静态好看不能替代动态证据。

## 5. 对《偷来半支舞》的具体应用边界

保留已认可人物、主题、半支舞、原曲、原画收尾；不另加重逢或浪漫支线。本轮修订的是执行逻辑，不把以下设想写成用户已验收分镜：

- 邀请应把她的目光和主动伸手放在同一动作内；男伴的回应提供下一步转身的支点。
- 舞步应包含可以读出的行进与转向，允许短暂的侧后视角。全身镜负责肩腰、承重与长裙，随后靠动作接近景读她转回来的笑；不要求六秒内一直全身、一直露脸、一直同一距离。
- 门开启后，她的注意转向入口，并顺势继续前进。用视线与跨门动作连接空间，不追加一次“站稳展示”，不让披肩为了满足前后画面而无故回肩。
- 入场保留充分的完整着装展示；在经过桌边时转为侧向关系，让灯、花与家具产生前后景变化。旁观者侧目可留在同框环境，不依赖反复插入他们的特写。
- 到桌边，向后交出披肩，右手到鬓边；在这里才把行动收束到真实原画姿态。

正式制作前的本地工作是把这些行为排成一条完整可剪的时间线，区分已经可复用的素材和真正缺失的正式段落，并核对最终提交文本是否仍在锁死动作。分段生成只是候选执行方式，须有当前模式与参考绑定证据；不能将 ARKE 的两段流程当成本片成功保证。

本轮没有重新开放付费生成。尚未解决的动态质量、裙料与整片效果继续如实标记为未完成。
