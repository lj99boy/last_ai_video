# 绘画短片：导演检查表

先用[按阶段的制作经验](production-lessons.md)选择本轮核心问题，本页按需展开。技术复核与导演复核应回答不同问题，不能靠增加同类检查者代替人物因果、正常速度和听感判断。反例见[第二作复盘](../works/0002-zaporozhian-reply/delivery/retrospective-2026-10-29.md)。

用于分镜设计与整片审看，按作品的观看重点选择检查项。它是设计和审片工具，不是模型能力保证或新增付费测试流程。方法来源见[早期公开调研](history/directing-research-2026-10-11.md)。

## 每个镜头先写这张卡

在镜头卡之前，先写整段的“发生了什么 → 谁怎样回应 → 观看感受有何变化”。找不到回应时，先确认是否刻意采用纯氛围路线，不用更多漂亮细节掩盖尚未讨论的故事。案例见[列宾参考片分析](history/reference-repin-screen-review-2026-10-12.md)。

| 项目 | 要回答的问题 |
| --- | --- |
| 感受 | 这一镜想让观众感到什么？如亲密、期待、惊艳、留恋 |
| 新发现 | 相比上一镜，观众多看见或多理解了什么？若没有，为何继续停留？ |
| 观看重点 | 先看哪里，动作后看哪里？人物、光、道具是否争抢注意？ |
| 动作 | 镜头开始时人物和物件是什么状态？谁发起动作，动作怎样结束？ |
| 约束的代价 | 人物严格遵守每条防错要求后，主要动作和动机是否仍成立？是否为避免局部碰撞、道具变化或齐整反应，反而取消了冲锋、用餐、连续工作或共同反应？时长预算是否被误用为表演硬上限？ |
| 人物反应与目的 | 人物注意到谁或什么，获得什么信息，下一步因此怎样改变？疼痛或威胁是否继续影响身体与选择？配角为什么留下、转身或离开？ |
| 构图和路线 | 起点、中点、终点的观看重点是否清楚？遮挡何时揭示主体，是否妨碍关键动作？ |
| 场面持续 | 主戏之外选择哪一件次要事件？开镜前是否已发生，切镜后位置和进展怎样延续？近景可只保留看得见或听得到的变化，不要求每人都动。 |
| 环境与受力 | 风、身体接触或重量分别带动什么？衣物、烟、草与道具是否相互一致，硬物或未接触物是否无故蠕动？ |
| 机位 | 景别、角度或运镜的变化带来什么意义？固定是否更合适？ |
| 明暗和材质 | 主体是否与背景分开？光线是否保留了本片关键色彩与材质的辨识度？ |
| 声音 | 近处动作、环境、音乐各做什么？声音何时进入/离开？ |
| 切点 | 信息何时清楚、动作在哪个阶段切、下一镜如何承接？不按平台生成时长机械保留整段 |
| 实现 | 现有素材可剪、可裁切预演、需补静帧，还是必须新生成动作？ |
| 表述 | 只读最终正文，能否说出谁做什么、动作针对谁或什么、物体怎样变化、摄影机从哪里看？是否漏字、缺宾语或让代词指错人？ |
| 输入范围 | 模型是否拿得到文中所依赖的参考与上下文？旅程省略、后接哪场、后期怎样处理等是否属于这次实际生成任务？ |
| 连续性依据 | “同一物件／仍在做”由本次哪份实际素材或明确描述支撑？缺失信息是否已登记，而非默认模型知道前场？ |

提交前再对照实际参考图检查：介绍场景的镜头能否看清人物所在位置、行动路线和前后距离；近景是否换了观察角度，人物能否按图中位置完成接触；每份参考分别提供什么。多张完整构图可能互相冲突，文字“依次”不等于已经验证镜头顺序控制。先复用、整理或减少冲突输入，不把每个背景动作自动转成一张新参考。

最终正文及采纳的复核建议都须重新读通，再核台词、静默和动作顺序；旧版通过或指纹一致不能代替文字复读。具体漏查案例与修正方法见[语言经验](history/practice-notes.md#2026-10-20--提示词与制作说明先让人读懂)。

先保护本段的必要事件和人物反应，再安排局部空间、防错和构图。物件连续优先核归属、交付和状态变化，不把“保持原样”当成全程不得使用；群体可以因同一件事并行反应，不为避免齐整而逐人排队。必要的情绪停顿和静态结尾仍按表达保留。反例和适用边界见[保留主要动作的经验](history/practice-notes.md#2026-10-21--处理落地空间时保留冲锋本身)。

更新取词版本时，核对主入口与章内入口的文件路径、实际正文和对应指纹；不能只改总入口或只改路径。历史与已执行来源保持原样。人类摘要若未进入最终请求，应记为误取风险，不称为已经提交的模型输入污染。

## 全画面的关系和动作阶段

先看主戏，再检查会改变剧情判断的配角、物件和背景动作。战斗中对照实际图，从枪托、枪口判断射向哪个敌人或哪片营外区域，检查是否穿过己方撤回者、接应者和车辆通道；不凭空补画外敌人解释错误朝向的枪口。画面中的交叠不直接证明真实命中，但若无法判断射击位置与目标的前后距离，也不能认定射击方向合理。换机位可以改变屏幕左右，不能把所有枪口朝一个屏幕方向当通用规则。

将图中的动作阶段写准确：伸手不等于扶稳，触地不等于已经撑住重量，递出不等于交付，严肃表情不等于工作尚未开始。检查物件归谁、纸是否已写、笔是否已落下、笑是否提前发生，以及某人离开或松手后，谁接住重量、什么物体因此移动。不可把想做的动作登记成完成结果。

动作发生不等于表演成立。受罚后仍扶着人、最后也走出了门，仍可能缺少可信的受痛反应、视线对象和离开机会。承担观察和判断作用的回看，要能让观众判断他在看谁，以及看见之后为什么行动或等待；配角也要继续追求自己的目的，不能只为主角让路。先修这些关系，再决定表情和动作强度，不要求每一次眼动都有明确的剧情功能。第二作的实际反例见创作者反馈与重设计（本地记录 `production/whole-film-v05-65s/opening-acting-v06/README.md`）；此前机械核心检查通过的采用建议已撤回，新的设计尚未证明有效。

发现整图逻辑有问题时，要从当前实际输入链中撤出或暂停，并同步分镜、制作卡、提示词、状态表和素材清单。保留原图及当时审查记录；“只参考脸/手/画风”的文字不会自动遮住图中的错误空间或阶段。文件/哈希检查通过与画面逻辑通过分别记录。

## 整段观看

- 先正常速度看一遍，标记首次走神的具体时刻，再回看原因；不是看完后笼统加“更电影感”。
- 检查是否连续多个相似景别、光线和动作强度；变化不必平均分配。
- 在全片相关场景中检查：主戏以外是否有持续事件，远处人物是否沿路线移动或继续做事；切镜后是否重启同一动作。介绍场景时，能否看懂行动路线、人物与环境的大小关系和前后距离，不能只靠增加天空或缩小画面称开阔。
- 先看主戏，再看必要的背景动作，以及风、碰撞和重量怎样影响物体；不要求每个近景看全所有层次。眨眼、草反复摇摆或运镜不能单独证明整个场面活起来；有意静止、情绪停顿与静态结尾按表达判断。
- 安静的镜头可以长，但要有持续可观察的变化或期待；不把快剪当万能药。
- 分别静音、有声观看；有声变好不能证明画面无需修改。
- 若重点是人物魅力，结合面容、姿态、动作和衣料判断，避免只有碎片化身体特写。
- 若选择回到原画，把结尾构图与人物最终位置一起设计；来源画作内容和画外扩展分开记录。
- 记录“生成成功、动作可用、剪辑可用、创作者认可”四种不同结论。

## 使用已有素材做低成本对照

保持主题、顺序、画幅与总时长相近。A 保留原剪辑并加临时声音；B 调整镜头选择和切点，使用相同声音素材与响度。必要时另导出 B 静音版，比较声音与画面的贡献。

先按本片目标选择少量比较项，例如空间是否易懂、事件是否推进、主体是否鲜明、是否还想继续看；不用模型能力或画质指标代替观看感受。裁切放大能否用于成片取决于源素材细节；预演可行不等于交付清晰度足够。临时音乐与音效记录来源，发布时核对使用依据。
