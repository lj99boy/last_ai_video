# 绘画短片：导演检查表

适用于用户和 Codex 在付费生成前、粗剪后共同检查。来源与适用边界见 [公开调研](directing-research-2026-10-11.md)。这是我们针对本项目整理的方法，不是安装的第三方插件，也不代替用户审美判断。

## 每个镜头先写这张卡

| 项目 | 要回答的问题 |
| --- | --- |
| 感受 | 这一镜想让观众感到什么？如亲密、期待、惊艳、留恋 |
| 新发现 | 相比上一镜，观众多看见或多理解了什么？若没有，为何继续停留？ |
| 观看重点 | 先看哪里，动作后看哪里？人物、光、道具是否争抢注意？ |
| 动作 | 起帧实际是什么状态？一个动作怎样开始、结束？ |
| 构图和路线 | 起点、中点、终点都可见吗？主要身形/手杯是否会被遮挡？ |
| 机位 | 景别、角度或运镜的变化带来什么意义？固定是否更合适？ |
| 明暗和材质 | 主体是否与背景分开？暖光是否吞掉银裙的银灰本色？ |
| 声音 | 近处动作、环境、音乐各做什么？声音何时进入/离开？ |
| 切点 | 在什么信息或动作完成后切？不按平台生成时长机械保留整段 |
| 实现 | 现有素材可剪、可裁切预演、需补静帧，还是必须新生成动作？ |

## 整段观看

- 先正常速度看一遍，标记首次走神的具体时刻，再回看原因；不是看完后笼统加“更电影感”。
- 检查是否连续多个相似景别、光线和动作强度；变化不必平均分配。
- 安静的镜头可以长，但要有持续可观察的变化或期待；不把快剪当万能药。
- 分别静音、有声观看；有声变好不能证明画面无需修改。
- 女主的脸、姿态、身段和衣料共同表达魅力，避免只有碎片化身体特写。
- 画作结尾与人物落点一起设计，来源画作内容和画外扩展分开记录。
- 记录“生成成功、动作可用、剪辑可用、用户认可”四种不同结论。

## 使用已有素材做低成本对照

保持主题、顺序、画幅与总时长相近。A 保留原剪辑并加临时声音；B 调整镜头选择和切点，使用相同声音素材与响度。必要时另导出 B 静音版，比较声音与画面的贡献。

先比较“进入空间”“服务有质感”“女主出场有变化”“还想继续看”四项，不用模型能力或画质指标代替这些感受。裁切放大只用于试节奏，若细节不足，再补真正近景。临时音乐与音效必须有可用来源，不能从参考影片抽取来发表。
