# 当前执行平台

更新：2026-10-29。本页只说明现在用什么执行、怎样安全执行；创作方法见[制作经验入口](production-lessons.md)，资源组织见[参考驱动的制作](reference-production.md)。平台、模型或入口变化时只改本页，并把旧内容移入[历史资料](history/README.md)。

## 现在用什么

| 用途 | 当前选择 | 说明 |
| --- | --- | --- |
| 视频生成 | 即梦，官方 `dreamina-canvas` CLI，Seedance 2.5 | 第二作全部正式生成使用此入口；m2v（多参考）为主，首尾帧等模式按段选择 |
| 画幅与清晰度 | 16:9；480p 用于预演和低成本比较，720p 用于入片 | 每次以当前 `model find` 返回的枚举为准，不沿用旧表 |
| 静帧与参考图 | Codex 内置图像工具，或已有素材整理 | 即梦 Seedream 图片在第二作中退出执行范围 |
| 剪辑、字幕、声音 | 本地 FFmpeg 与作品内脚本 | 回画、字幕、片尾资料优先本地合成，不为此调用生成 |
| 资源编排 | [参考流水线工具](../tools/README-reference-pipeline.md) | 编译、读回比较与授权差额检查；不替代审看 |

## 每次执行前

1. **核实实际执行链。** 读作品当前入口，确认本轮平台、模型、项目和允许动作。技能存在、文件名、旧授权都不是执行依据。
2. **逐次授权。** 每次付费生成都需要创作者明确许可，并写清范围和积分上限。CLI 的 `--credit-ceiling` 是技术阈值，不等于创作者授权；上限内改了内容也要重新确认。
3. **离线检查最终文件。** 上传前检查最终裁图的尺寸、宽高比和内容，而不只是原图。已观察到的拒绝条件见下表。
4. **保存、读回、核价分开确认。** 草稿保存成功、读回一致、报价通过、允许扣费、生成成功、创作采用，是六件不同的事。
5. **记录费用口径。** 报价预留不等于净扣；只有查过账户才写净扣，未知就写未知。

## 已观察到的入口条件

以下都是带日期的同入口观察，**不保证适用于其他模式、其他平台或以后的版本**。用途是提前排除明知会被拒的输入。

| 观察日期与入口 | 发生了什么 | 之后怎样提前检查 |
| --- | --- | --- |
| 2026-10-21，Seedance 2.5／m2v 参考图 | 1280×350 的图被拒，`materials[0].aspect_ratio` 为 3.657，要求不超过 2.5 | 测最终文件宽高比，大于 2.5 先改图 |
| 2026-10-24，Seedance 2.5／m2v 参考图 | 260×256 的局部图被拒，`materials[2].width_px` 要求宽度至少 300 像素 | 测最终裁图宽度，小于 300 像素先改图 |
| 2026-10-17，官方 CLI 引用解析 | 正文中的引用按第一次出现的顺序决定槽位，`--ref A --ref B` 不能强迫正文“先 B 后 A” | 调整参考顺序时，同时调整正文里第一次引用的顺序 |
| 2026-10-15，`node create video` | 不加 `--run` 只创建节点；`--dry-run` 只做本地校验，不写远端、不报价 | 先 dry-run，再保存，再报价，最后按授权运行 |

## 账号与安全

- 账号、余额、令牌和带鉴权参数的链接不进仓库；本仓库是公开仓库。
- 项目 ID、节点 ID 可写在作品的本地执行记录里，不写进通用文档。
- 本项目每月新增工具支出上限为人民币 100 元（不含已有 Codex 订阅）；这是预算约束，不是付费授权。
