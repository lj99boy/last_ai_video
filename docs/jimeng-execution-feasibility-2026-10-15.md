# 即梦执行侧替换评估

核查日期：2026-10-15。范围：评估后续作品的图片/视频生成能否从 LibTV 转到即梦，保留共创、导演稿、素材归档和本地剪辑。本文是有日期的调查结论，不代表已迁移或已授权付费。

## 判断

具备迁移路径，优先评估官方 **即梦画布 CLI（`dreamina-canvas`）**。它的本机命令契约已覆盖上传、参考绑定、草稿读回、报价、消费上限、任务查询及下载。接入前还需用目标账号确认模型、会员权益、素材准入和实际报价。

当前状态是“官方入口和本机接口已核实，账号尚未接通”，不能写成“已替换 LibTV”。换平台也不保证动作、材质、镜头表达自动变好；即使模型名称相似，也不能推定版本、模式、默认参数和效果相同。

## 对现有工作流的适配

| 能力 | 即梦当前证据 | 迁移时处理 |
|---|---|---|
| 本地参考图、视频、声音 | `resource upload` 存在，区分本地上传与外部生成素材 | 上传后需登记资源；运行时准入仍需验证，导入类别不等于素材审核通过 |
| 人物、材质、连续性等多参考 | `node create/edit video` 支持 `m2v` 和显式引用 | 按实时模型规格确认数量/类型；不能把多参考误填成首尾帧 |
| 首帧/尾帧 | `first_last_frame` 接受一个首帧或两个有序帧 | 保持首尾顺序及比例要求，不用于任意三张参考图 |
| 提示词与参考对应 | 官方协议提供节点/资源引用及正文占位符，支持读回 | 将 LibTV 占位符转换成即梦语法，再核对保存后的正文与引用关系 |
| 精确报价 | `node quote` 声明为只读 | 先保存具体草稿再报价；未保存的计划和纯本地校验不构成报价 |
| 消费上限 | `node confirm --credit-ceiling`；媒体组合命令也有上限参数 | 使用有范围的既有授权；不使用代表无限金额批准的 `--yes` |
| 防重复提交 | 官方协议以稳定 `submitId` 识别同次运行 | 本地先落记录；超时先查询原任务，不换 ID 自动再生成 |
| 状态与下载 | `operation status/wait`、`resource download` 存在 | 区分受理、完成、选片和文件下载；仍需实际验证原始文件和导出权益 |
| 音频关闭 | 本轮视频创建/编辑帮助未见独立音频开关 | 尚不确定能否复现 LibTV 的声音关闭配置；后期静音不等于生成时关闭或节约费用 |
| 本地后期 | 现有 FFmpeg 流程消费本地媒体 | 可以保留；按新素材实际时长、帧率、尺寸重新安排剪辑点 |

上表“命令存在”来自实际 `schema/help`；远端行为、扣费协议来自官方说明，尚未以登录或付费任务验证。具体 Seedance 版本、12 秒/720P/16:9 与多图组合必须以登录后的模型规格为准，不能从通用命令参数推定可用。

现有作品的实际配置以 [A/B v02 记录](../works/0001-in-london/production/film-v06/whole-film-v02-configuration.json) 和 [B v03 记录](../works/0001-in-london/production/film-v06/whole-film-v03-configuration.json) 为依据：最终采用的 A 为两图、B v03 为三图，均 12 秒、720P、16:9、一次一条、声音关闭。B 的连续性参考含 A 的真实结束静帧。早期 [execute.py](../works/0001-in-london/production/film-v06/execute.py) 不能代表整部最终成片的全部执行过程。

## 接入范围

保留已确定的创作简报、导演稿、人物与衣料参考、每段叙事职责、镜头衔接、素材指纹和 [本地剪辑交付](../works/0001-in-london/delivery/reproduce-v03.md)。已交付作品继续归档，不为验证即梦重新生成。

需要更换的是生成入口、素材/节点 ID、提示词引用语法、模型参数、报价和任务状态/下载处理。现有脚本没有通用平台接口，不能只替换 CLI 路径。后续实现宜增加一个小型即梦执行器，保留 LibTV 历史记录，不先搭大型多平台框架。

除金额上限外，执行器仍需核对已批准的输入、提示词与参数。官方积分协议允许最新草稿在上限内继续运行；价格没有增加不代表用户已经认可内容变化。

## 火山引擎 API 备选

方舟 Seedance API 是另一条官方开发者路线，不能把它的价格、开通规则和素材政策当成即梦会员或画布 CLI 的规则。未验证两者权益互通，不按共用积分计算。

2026-10-15 核查的官方资料显示：

| 项目 | API 当前资料 | 对本项目的影响 |
|---|---|---|
| 模型与规格 | `doubao-seedance-2-5-260628`，多参考支持 1–30 图、4–30 秒、720p、16:9 | 12 秒、三图的参数需求覆盖；尚无本账号执行证据 |
| 模式 | 严格首尾帧与多参考分开，2.5 首尾帧比例为 `adaptive` | 三图走参考模式；不能直接复制 LibTV 模式名 |
| 开通 | 余额大于 200 元，或购买不少于 200 元专属节省计划，或拥有可用对应资源包，满足其一 | 属于资金/权益门槛，不是月费，也不代表实际单次消费 |
| 价格 | 无视频输入、720p 为 70 元/百万 token | 12 秒、1280×720、24fps 按公式估算 259,200 token，约 18.14 元/次；准确金额以实际用量与计费为准 |
| 试片 | Draft 与正式生成分别计费 | 不是免费试跑；生成成功但创作效果不满意的重做仍会产生费用 |

规格及开通来源：[创建视频任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[Seedance 2.5 官方教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)；费用及公式来源：[官方模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)。估算公式为 `12 × 1280 × 720 × 24 ÷ 1024 × 70 ÷ 1000000`，不是即梦画布报价或实际账单。

人物素材是单独的迁移条件。API 不支持直接上传含真人人脸的参考图/视频；其含人脸模型产物信任机制限定同一方舟账号、近 30 天、指定模型的原始输出，不覆盖跨平台、跨账号或二次剪辑产物。另有预置虚拟人像、本人认证授权素材路径。不能因此承诺现有 imagegen 人物图或 LibTV 视频直接可用，也不能把全部虚构人物一概判断为禁止；需核实具体素材适用路径。来源：[官方肖像素材指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)。这项 API 政策不直接外推给即梦画布。

因此 API 暂列备选：规格足够，但不能仅凭估算单价得出更省钱的结论；资金门槛与素材迁移成本也要纳入选择。

## 成本与验证顺序

目前没有即梦账号的同参数报价，不能给出相对 LibTV 的节省百分比。LibTV 历史积分报价保留在[费用记录](libtv-costs-and-operations.md)，不能与即梦积分直接按一比一比较，也不能拿不同模型、分辨率或过期促销作同等质量对照。

下一步先完成一次不生成的接入核对：

1. 确认是否已有可用即梦会员，按官方流程完成 CLI 登录；会员档位、积分、模型与导出权益分别确认。
2. 查询当前可用模型，确认实际需要的多参考、时长、分辨率、比例与声音行为。只查目标路线，不重复普查所有平台。
3. 在明确接入范围后，用已选参考保存草稿，读回并取得逐项报价，核对素材格式及已公开的准入要求；生成时审核是否接受仍待实际任务确认。上传/保存属于远端变更，不冒充只读检查。此阶段不提交生成。
4. 对比整片所需费用、会员新增支出、预计可用产出及合理修复空间。账号余额和套餐理论秒数均不能替代实际成片成本。
5. 若决定采用，第一笔生成优先服务下一部作品的正式段落。仅当仍有会改变制作选择的关键动态未知时，考虑能入片或迁移的代表段落，并明确上限；不为“证明平台能生视频”额外购买试片。

在接通、核价和导出条件明确前，LibTV 保持可回退入口。制作质量继续依赖整片设计、参考职责、动作可行性和剪辑衔接；平台迁移解决执行与成本选择，不能代替这些工作。
