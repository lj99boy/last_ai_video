## 样片与高清入口（2026-10-12 核查）

- 官方 CLI 模型：`Seedance 2.5（样片模式）`，key `star-video2.5-draft`；在线 schema 确认480P，4–30秒、步长1秒、一次1条，支持单图与首尾帧。480P动态已由S003D实测得到，但帽型漂移，整条未采用。
- 用户截图写明“480P低成本试片，满意后直出高清版本”；已有样片中也确实出现原生“生成正片1080P”入口。其内容保真和实际产出尚未验证，不能承诺逐帧不变。
- 视频上方工具栏的“高清”实际新建Topazlabs超分配置节点，和样片原生“生成正片”不同。该入口会修改画布，不能当成纯查看弹窗。本次误入创建的临时节点v-VdekyAn4aH已通过官方CLI删除，从未执行。
- 当时CLI的help/schema未见原生样片转正片的专用命令；搜索视频模型“高清”无匹配。这不支持把样片模型分辨率强设1080P，或将Topaz超分称为原生正片。
- 网页选中节点后报价异步加载，首次DOM读取可能没有数字；读取参数后完成其他工作，再读取该节点即可。只看即时空值不能断言平台没有报价。

## 执行顺序（2026-10-13修订）

整片声画设计与已有资产清点 → 实际参考/提示词/配置核对 → 选择能够完成正式段落的制作路径 → 本地剪辑与完整观看。原先固定“480P样片后升级”的顺序不再作为通用规则。

只有代表样片能解除关键动态未知、改变下一步选择，且结果可迁移到正式制作或直接采用时才试拍。低分辨率/不同模式样片不能自动证明正式模式可靠；原生转正片保真未实测，不能预设省钱。比较包含测试、正式制作、升级和可能返工的全片成本。优先让一次正式段落兼具验证与交付作用，不重复购买已知证据；具体作品已有授权继续有效。失败先定位问题，不为错误素材付升级费，不把超分误称为重新生成高质量动作。

按未解问题跨镜号/版本累计付费；无新证据不继续重试。预算还需覆盖剩余成片和合理修复空间，不能把账户余额当成无限测试额度。方法见[画作到故事制作方法](painting-to-story-playbook.md)。以下S003F等保持历史记录，不作为当前执行指令。

历史案例：S003F配置为12秒首尾帧480P样片候选，复用两张参考帧，纹理描述更新为保留有依据的断续油彩；单次执行完成后因入场披肩动作反向被否决，未采用、未重试。该阶段的高清预算和原生升级方式尚未解决；后来采用的720P标准生成与剪辑路径见下方执行记录。
