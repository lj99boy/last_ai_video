## 样片与高清是不同步骤

- 官方 CLI 模型：`Seedance 2.5（样片模式）`，key `star-video2.5-draft`；在线 schema 确认480P，4–30秒、步长1秒、一次1条，支持单图与首尾帧。480P动态已由S003D实测得到，但帽型漂移，整条未采用。
- 用户截图写明“480P低成本试片，满意后直出高清版本”；已有样片中也确实出现原生“生成正片1080P”入口。其内容保真和实际产出尚未验证，不能承诺逐帧不变。
- 视频上方工具栏的“高清”实际新建Topazlabs超分配置节点，和样片原生“生成正片”不同。该入口会修改画布，不能当成纯查看弹窗。本次误入创建的临时节点v-VdekyAn4aH已通过官方CLI删除，从未执行。
- CLI当前help/schema未见原生样片转正片的专用命令；搜索视频模型“高清”无匹配。不要猜HTTP请求、把样片模型分辨率强设1080P，或将Topaz超分冒充原生正片。
- 网页选中节点后报价异步加载，首次DOM读取可能没有数字；读取参数后完成其他工作，再读取该节点即可。只看即时空值不能断言平台没有报价。

## 执行顺序

静帧验收 → 单次480P样片 → 检查动作、帽型、胸花、材质与接镜 → 合格片再核对原生正片费用并升级 → 高清产物复核后进入成片。失败样片先定位原因，不为错误帽型付升级费。不得把样片放大当成已完成高清。

S003F已配置为12秒首尾帧480P样片候选，复用已上传的两张参考帧，纹理描述更新为保留有依据的断续油彩，后续单次执行完成，但因入场披肩动作反向被用户否决，不采用、不重试。全片目标没有改成只交样片；高清预算和原生升级执行方式仍待解决。
