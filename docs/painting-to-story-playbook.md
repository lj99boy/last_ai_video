# 从一幅画到完整故事：制作方法

本页说明**方法为什么这样做**；实际开工按[制作经验入口](production-lessons.md)只读当前阶段，再回到这里查相关部分，不另抄一套检查表。方法来自[首作复盘](../works/0001-in-london/delivery/retrospective-2026-10-13.md)和[第二作复盘](../works/0002-zaporozhian-reply/delivery/retrospective-2026-10-29.md)，尚未由下一部作品证明节省比例，不保证模型一次必成。

故事声画、空间观看、可复用资产、段落参考组合、执行与整段审片是一个闭环，资源部分见[参考驱动的制作](reference-production.md)。不默认先画每镜精细构图，再将图片动起来；多图、Element和参考视频均按信息需要择用，能力支持与本片效果分别验证。

2026-10-16增补：结合[第二作G03的实际输出与创作者反馈](history/practice-notes.md#2026-10-16--主角动起来仍不等于整个场面活起来)，补齐持续背景、空间尺度及多图构图职责。以下是针对已观察问题的设计与验收改进，尚不能宣称新方案已由生成效果或节省比例验证。

## 1. 先找到值得扩展的瞬间

先共同确定观众看完最应记住什么，再设计事件。可以是一个人的魅力、一段关系、一个悬念、某种时代气氛，不必强行变成复杂剧情。

观察原画中的姿态、视线、人物距离、道具、材质、光线和空间；分别记录画面事实、创作解读与新增虚构。问两个问题：什么刚刚发生，才使人物停在这里？如果画面继续一秒，又会发生什么？据此提出少量具体事件方案，说明哪一处原画细节支撑它。

一个可用故事应有可见的行动链：角色的愿望或注意 → 主动行动 → 他人或环境回应 → 状态变化。计划由画面承担的关键因果，应在画面中成立；声音承担的叙事信息则在完整声画中验证，不一律要求静音后仍完整读懂。以审美体验为主的短片可以不设强冲突，但不能只有不断重复的漂亮展示。

从原画向前、向后扩展，也从预定结尾倒推，两端在同一行动链上会合。是否准确回画由本片决定；若需要，手、衣物、道具与空间的最终状态在开拍前就进入设计。

## 2. 只对齐会改变整部作品的选择

Codex先看画并给出建议，让创作者选择方向，不把导演工作变成一长串问卷。开工时合并对齐：

1. **观看重点和取舍顺序**：最打动人的是什么；美感、故事、氛围、原作忠实度发生冲突时优先哪项。
2. **改编空间**：保留哪些识别点；允许哪些事件、人物关系和空间扩展。给具体情节提案，不只给“浪漫/高级”等词。
3. **视觉和动态基准**：选少量图或短片校准外观与运动。身份认可、衣料认可、动作认可分别记录，不能互相代替。
4. **完整交付与预算**：画幅、声音、原曲选择、片长弹性、结尾形式、最终尺寸；本片总预算、可执行额度和返工余量。

已有明确答案直接沿用。镜头细节和参数由Codex自主完成；只在主题、人物关系、关键审美或总支出发生实质变化时合并讨论。建议、可接受范围、已确认要求和候选效果分开记。

## 3. 研究要改变具体制作决策

按当前最大的未知寻找参考，不泛搜一堆“电影感”资料。优先研究三类证据：

| 要解决什么 | 主动找什么 | 实际拆解什么 |
| --- | --- | --- |
| 单幅画如何扩成故事 | 原画改编、短片、同类情绪场景的完整作品 | 行动、回应、信息何时出现，结尾如何获得意义 |
| 身体与衣料怎样自然好看 | 同类剪裁、长度、材质和动作条件的真实走秀/表演 | 承重、步幅、转身、裙摆滞后与回落、光区变化；不只看一帧 |
| 生成路线怎样可控 | 有输入、输出和过程的同类制作案例；相关Skill正文 | 实际模型/模式、参考职责、生成分段、可剪范围；有无失败及成本披露 |

先看原速动作，再定位关键段；声音相关问题必须听，无法直接听辨时明确说明。截图、文字介绍、作者宣传和实际播放属于不同证据。刚体广告的成功不能证明双人握持或薄裙可靠；Skill中的限制也不能覆盖本片目标。

每条真正采用的经验只留一张简短记录：**来源片段 → 看见的机制 → 本片哪一镜怎样改变 → 输入如何落实 → 能观察的结果 → 不适用之处**。找不到本片落点，就还没有完成吸收。足够回答当前问题便停止搜索；条件变化或证据矛盾时再定向更新。

## 4. 分镜组织观看，不堆镜头术语

先排完整声画过程，再决定镜数、生成段数与长度。三者不是同一个指标。

每镜只需回答：观众新发现什么？谁发起行动？为什么此时换视角或切镜？前镜的哪一步在这里继续？下一镜接到什么？声音怎样参与？

让主体突出，可以靠他主动行动、镜头重点拍他，或多给他的反应，不等于让配角消失、主体始终正面或始终全身。全身镜头展示身体和服装，中近景表现感受、细节或人物关系；视角变化来自事件，不为覆盖镜头清单硬加环绕。允许固定镜头、背面和短暂遮挡，只要观众仍能及时看清本镜的重要信息。

全片共用一条动作时间线。方向、站位、握持关系和衣物状态不能因切镜重新开始；中间段落不必都收步站稳。预留可剪动作，最终按真实素材切点剪，不按提示词中的整数秒机械截断。

空间先于精细成品图：先核人物相对位置、进出、道具归属、接触点与行动通道，再比较换观察位置后能看见什么新信息。摄影机可以留在同侧、换到另一侧、固定或移动，也可以在动作进行中切镜，以是否易懂和有表现力决定；不能用“始终同侧”替代连续性判断，也不为变化强制跨轴。空间草图检查关系，白模排演检查路径与时序，两者均不是最终画风或自然表演已经通过的证据。

对需要持续生活或环境压力的场景，在主戏之外选一件有进展的次要事件，如旁人继续劳动、让路后回到任务、远处队伍沿路线移动。它应在开镜前已发生，切镜后位置和进度延续；不把每个配角都另写一条戏。写清风怎样吹动草、水面、烟、旗布和宽松衣角，人物碰到物件后它怎样移动或变形；硬物、未碰道具和有意静止的人可以不动。近景只保留视野内的事件或相应的声音，不要求每镜前中后层齐全、全员持续活动；摄影机漂移、眨眼或反复吹动草木不能替代背景事件。

按观看任务设计景别与通道：介绍场景的镜头要让观众看懂人物在哪里、能沿什么路线移动、前后距离如何；关键接触仍要看得清。近景则重点表现人物之间的反应，以及谁扶住谁、谁撑着物体等受力关系。整体缩小同一张图、增加天空或数码推拉不自动得到更好的空间。把这些要求贯穿整片相关场景，不仅修一条被指出僵硬的镜头，也不为丰富角度机械增加镜头数。

## 5. 从资产分工形成每个段落的参考组合

先清点已有有效资料，再按信息分工：身份与当前年龄、身形衣装、环境、关键道具、画风、动作与摄影、声音、需要严格衔接的开始或结束状态。素材的认可范围与不采用内容一起记录，同一属性不能有互相矛盾的主要基准。跨龄作品按当前年代选择资料，核对可辨面部特征、身形与人物关系，不把各年龄图无说明混成同一参考。造型仍要将脸、身形、剪裁、材质和光线一起看。

每个实际制作段形成简明组合：**故事与注意顺序 → 人物／场景／物件的当前关系 → 实际引用及各自用途 → 模式与源素材时长 → 前后依赖 → 核心验收**。可以引用单人图、环境图、道具图、风格资料、音视频、空间草图、关键帧或可复用主体；哪些不需要由镜头任务决定，不预设每镜参考数、三视图或必须有精细成品图。具体用法和边界见[参考制作细则](reference-production.md)，填写用[参考计划模板](../templates/work/preproduction/reference-plan.md)。

生成图不能一代代取代原作。选角资料不规定镜头构图或全程正脸；环境资料不继承旧人物位置；风格资料不自动带入其角色、年代和情绪；动作图不自动改变身份。图像仍携带不希望继承的信息时，要换资料、另行裁选或减少引用，不能只靠“仅参考某属性”抵消明显冲突。简单镜头可先用独立人物、环境等资料和文字设计；复杂双人接触、食物或物品交接、多人肢体关系或精确回到原画等，才按风险补完整关系图／关键帧。清晰的局部和简图够用时，不为好看再买一张全幅美图。

多张完整构图可能给出冲突的机位、景别、姿势和情绪；它们的上传顺序不保证生成镜头按此排列。Element的主／辅素材与音色用于组织复用，不是LoRA或人物／环境／风格硬权重，也不必成为所有镜头的前提。模式按目的选择：多模态参考留出重新构图空间；首尾帧用于确有起止状态需求的段落；确定的裁切、溶解、显示画框、字幕和剪点优先由本地制作承担。支持某种输入不等于本片的人物一致性、接触动作或镜头顺序已验证。

提交前对照**导演原文与整片计划、实际审看的素材及用途、最终提交词、保存后的读回配置**，逐段核机位、主要动作、年龄、开始和结束状态、声音与引用。重点找计划跟拍却提交固定、需要转身却强制露脸、资料已松手却要求从握持开始、多幅图给出矛盾的开镜画面、前段实际结束状态不合格却启动后段等矛盾。保留主要因果与必要约束，删掉无用的琐碎指令，不把完整导演稿复制成越来越长的提示词。正文还须能独立读懂，具体检查见[参考制作细则](reference-production.md#4-每个实际制作段的组合)。

静帧检查外观和关系；简易排演检查空间、方向、时序；两者都不证明自然动态。材质要在完整动作周期中看：布料怎样被身体带动、怎样滞后回落、反光怎样随受光变化。原作精确展示需要真实来源与实际转场核对，不能依赖普通多参考逐像素复原。

## 6. 用付费制作完成作品

先清点已付费资产，再列真正缺失的连续段落。全片预演优先用现有图、视频和实际配乐，必要才补关键图。复杂空间才用简易三维；不默认搭一套重制作系统。

**代表样片不是强制环节。** 只有关键动态未知会影响大范围制作、测试能改变下一步选择，而且结果可迁移或直接入片时才值得付费。已有同条件证据就复用；不同模式、人物、材质或低分辨率样片不自动证明正式片可靠。默认尽可能让第一次正式段落同时承担验证与交付作用，不能先买整套测试再买整套重拍。

连续动作可放在同一生成段，段与段在自然可剪处拆开；先列后段需要的人物／器物状态，等前段出现实际可用片段后再配置，不押“最后一帧应该正确”。可以通过明确切镜省略无叙事价值的短距离移动，但后镜状态须合理成立，不能靠物件消失伪装无缝衔接。分段越长，局部失败可能重做的范围越大；精确镜头顺序是否可实现须由实际输入和输出判断，不将“一次生成多个镜头”推广成“一次生成全片”。

预算覆盖完整完成路径：已用额度、剩余正式制作、可能的升级、声音、修复余量和当前报价。余额不是可用预算，充值也不等于全部授权试验。不虚构一个固定返工百分比；至少说明最可能失败的关键段若需替换，预算是否覆盖、不能覆盖时怎么取舍。未经授权不自动用完余量。

经济性看总投入和最终采用价值，不只看每秒单价。引用当前记录时区分报价、余额差、逐任务实扣、人民币与未知项；“关闭音频”“先480P后高清”“视频编辑保留动作”都必须有对应证据才可宣传为省钱。

执行前检查新增操作的授权：实际新增媒体、上传目的地、草稿／主体等云写入范围与消费上限分别是什么，既有许可覆盖则直接沿用，超出才确认。引用、模式、时长、数量或模型改变后须重新保存读回并核价；旧报价与余额不能代替当前请求的价格和授权。允许输入的素材数量上限不是每次要用满的目标，拆分参考和Element也不预设会更便宜；核价成功、运行成功与创作通过分别记录。

## 7. 失败后按问题收敛

首次简单问题沿现有任务记录；反复出现或牵涉高成本取舍的未解问题才建立稳定ID，跨镜号和版本累计尝试。一次付费失败后，下一次之前必须说清：原来假设是什么、得到什么新证据、输入/表现方案改变什么、再花钱预计解决什么。同问题换名字不清零。若已有充分证据表明输入正确而失败来自随机性，可以提出保持输入的受控重抽，说明价值、次数上限并核对已有授权；不能为了满足流程乱改正确参数，也不能自动重跑。

| 判断 | 优先动作 |
| --- | --- |
| 主题/观看价值没成立 | 回到整片事件和观看结构，不批量生成局部补丁 |
| 图像或状态有矛盾 | 检查段落参考组合、实际素材与读回，修冲突职责，不能仅追加否定词 |
| 接镜或时长问题 | 先同时调整前后两侧剪辑，保留好表演 |
| 模型无法稳定实现核心动作 | 简化交互或改用另一种表达，再决定是否付费；不降低核心审美来假称完成 |
| 偏离提示但对整片有价值 | 作为创作偶然性评估，不因“不听话”自动重拍 |
| 没有新的可检验假设 | 停止该问题的付费循环，提出具体取舍 |

严重穿帮、核心人物或衣物突变是硬问题；光色差异、短暂遮挡等应结合镜头职责判断。重要选择集中交创作者，不把每个可自主剪辑的小差异都抛回去。

## 8. 检查和学习都以整片为单位

低成本输入检查 → 一次完整导出 → 原速带声审片 → 合并问题表。抽帧用于定位问题；解码、帧率、响度用于技术检查，均不能替代人的运动观感和听感。有新改动或未解风险才复查对应范围，不重复跑无变化的检查。

原速审片先追主戏的行动与回应，再看远处相关事件是否继续、人物路线是否看得懂、风和接触是否引起相应的物件变化；留意切镜后是否同一动作重启、主角之外是否像静态背景。前后抽帧可辅助比较位置，不能独立证明自然节奏。允许有意的安静、人物停顿和静态原作结尾。验收项增加不产生额外付费测试义务；先复核已有素材及前后镜头剪辑，再凭新证据和授权决定最少必要制作。

先审整个连续场面及前后镜头剪辑，再审全片；需要表现不同年龄、多人共同完成任务或回到原画的作品，加核这些具体任务。按实测条件更新资源、参考组合和下一段计划：某模式中新机位仍认得角色，不证明另一个年代或复杂群戏已通过；接口和dry-run可用更不等于云生成质量。保留有价值的意外表演，用实际剪点和选用区间更新计划。

交付时区分完整候选、创作者定稿、实际发布和传播结果。“目前就这样”可以意味着停止改动，不能改写成全部问题消失。完成标准在开拍前约定，不能到最后才发现还缺声音、分辨率或准确结尾。

下部作品用少量指标检验方法：首次全片前因目标/参考矛盾而作废的生成、同问题付费次数与消耗、最终采用素材比例、从方案到整片的时间、首次整片后还剩多少核心问题。成本降低不能以减少必要镜头或丢掉核心表达为代价。
