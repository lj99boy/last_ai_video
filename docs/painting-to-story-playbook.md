# 从一幅画到完整故事：制作方法

2026-10-29补充：[按阶段使用经验](production-lessons.md)负责实际触发检查，[第二作复盘](../works/0002-zaporozhian-reply/delivery/retrospective-2026-10-29.md)保存反例与结果。本页提供方法说明；开始一轮制作只引用当前问题相关部分，不另抄一套检查表。

更新：2026-10-13。来源是[《在伦敦》完整复盘](../works/0001-in-london/delivery/retrospective-2026-10-13.md)。这是对已知失败原因的改进方法，尚未由下一部作品证明节省比例，不保证模型一次必成。

## 1. 先找到值得扩展的瞬间

先共同确定观众看完最应记住什么，再设计事件。可以是一个人的魅力、一段关系、一个悬念、某种时代气氛，不必强行变成复杂剧情。

观察原画中的姿态、视线、人物距离、道具、材质、光线和空间；分别记录画面事实、创作解读与新增虚构。问两个问题：什么刚刚发生，才使人物停在这里？如果画面继续一秒，又会发生什么？据此提出少量具体事件方案，说明哪一处原画细节支撑它。

一个可用故事应有可见的行动链：角色的愿望或注意 → 主动行动 → 他人或环境回应 → 状态变化。计划由画面承担的关键因果，应在画面中成立；声音承担的叙事信息则在完整声画中验证，不一律要求静音后仍完整读懂。以审美体验为主的短片可以不设强冲突，但不能只有不断重复的漂亮展示。

从原画向前、向后扩展，也从预定结尾倒推，两端在同一行动链上会合。是否准确回画由本片决定；若需要，手、衣物、道具与空间的最终状态在开拍前就进入设计。

## 2. 只对齐会改变整部作品的选择

Codex先看画并给出建议，让创作者选择方向，不把导演工作变成一长串问卷。开工时合并对齐：

1. **观看重点和取舍顺序**：最打动人的是什么；美感、故事、氛围、原作忠实度发生冲突时优先哪项。
2. **改编空间**：保留哪些识别点；允许哪些事件、人物关系和空间扩展。给具体情节提案，不只给“浪漫/高级”等词。
3. **视觉和动态基准**：选少量图或短片校准外观与运动。身份认可、衣料认可、动作认可分别记录，不能互相代替。
4. **完整交付与预算**：画幅、声音、原曲选择、片长弹性、结尾形式、最终尺寸；本片总预算、可执行额度和返工余量。

已有明确答案直接沿用。镜头细节和参数由Codex自主完成；只在主题、人物关系、关键审美或总支出发生实质变化时合并讨论。建议、可接受范围、已确认要求和候选效果分开记。

## 3. 研究要改变具体制作决策

按当前最大的未知寻找参考，不泛搜一堆“电影感”资料。优先研究三类证据：

| 要解决什么 | 主动找什么 | 实际拆解什么 |
| --- | --- | --- |
| 单幅画如何扩成故事 | 原画改编、短片、同类情绪场景的完整作品 | 行动、回应、信息何时出现，结尾如何获得意义 |
| 身体与衣料怎样自然好看 | 同类剪裁、长度、材质和动作条件的真实走秀/表演 | 承重、步幅、转身、裙摆滞后与回落、光区变化；不只看一帧 |
| 生成路线怎样可控 | 有输入、输出和过程的同类制作案例；相关Skill正文 | 实际模型/模式、参考职责、生成分段、可剪范围；有无失败及成本披露 |

先看原速动作，再定位关键段；声音相关问题必须听，无法直接听辨时明确说明。截图、文字介绍、作者宣传和实际播放属于不同证据。刚体广告的成功不能证明双人握持或薄裙可靠；Skill中的限制也不能覆盖本片目标。

每条真正采用的经验只留一张简短记录：**来源片段 → 看见的机制 → 本片哪一镜怎样改变 → 输入如何落实 → 能观察的结果 → 不适用之处**。找不到本片落点，就还没有完成吸收。足够回答当前问题便停止搜索；条件变化或证据矛盾时再定向更新。

## 4. 分镜组织观看，不堆镜头术语

先排完整声画过程，再决定镜数、生成段数与长度。三者不是同一个指标。

每镜只需回答：观众新发现什么？谁发起行动？为什么此时换视角或切镜？前镜的哪一步在这里继续？下一镜接到什么？声音怎样参与？

主体突出靠行动发起、摄影机注意力、景别与反应分配，不等于配角消失、主体始终正面或始终全身。全身负责身体和服装，中近景负责感受、细节或关系；视角变化来自事件，不为覆盖镜头清单硬加环绕。允许静镜、背面和短暂遮挡，只要它们按时兑现本镜的观看价值。

全片共用一条动作时间线。方向、站位、握持关系和衣物状态不能因切镜重新开始；中间段落不必都收步站稳。预留可剪动作，最终按真实素材切点剪，不按提示词中的整数秒机械截断。

## 5. 参考管理与提交前核对

人物身份、衣料、动作、空间、画风、结尾各有当前主基准，标明参考负责什么、不负责什么。同一项不能同时引用互相矛盾的标准。图像本身冲突时先整理参考，不能指望一句“只参考材质”必然消除姿态或厚度影响。

生成图不能一代代取代原作。选角图不成为所有镜头的固定构图；动作姿态图也不自动改变脸或服装。造型应将脸、身段、剪裁、材质和光线一起看，避免局部光泽改善却改变人体轮廓。

付费前对照四样东西：**整片计划、实际起止图/参考、实际提交提示词、工具读回配置**。重点找矛盾：计划跟拍却提交固定；需要转身却要求全程露脸；图里已脱肩却要求从覆肩开始；需要连续走动却每镜规定停稳。保留主动作和关键约束，删除不必要的微观指令，不能把“整体思考”变成越来越长的提示词。

静帧检查外观和构图；简易排演检查空间、方向、时序；两者都不证明自然动态。材质要在完整动作周期中看：布料怎样被身体带动、怎样滞后回落、反光怎样随受光变化。

## 6. 用付费制作完成作品

先清点已付费资产，再列真正缺失的连续段落。全片预演优先用现有图、视频和实际配乐，必要才补关键图。复杂空间才用简易三维；不默认搭一套重制作系统。

**代表样片不是强制环节。** 只有关键动态未知会影响大范围制作、测试能改变下一步选择，而且结果可迁移或直接入片时才值得付费。已有同条件证据就复用；不同模式、人物、材质或低分辨率样片不自动证明正式片可靠。默认尽可能让第一次正式段落同时承担验证与交付作用，不能先买整套测试再买整套重拍。

连续动作可放在同一生成段，段与段在自然可剪处拆开；依赖前段状态的后段等实际结果再配置。分段越长，局部失败可能重做的范围越大，故不将“多镜整段”推广成“一次生成全片”。

预算覆盖完整完成路径：已用额度、剩余正式制作、可能的升级、声音、修复余量和当前报价。余额不是可用预算，充值也不等于全部授权试验。不虚构一个固定返工百分比；至少说明最可能失败的关键段若需替换，预算是否覆盖、不能覆盖时怎么取舍。未经授权不自动用完余量。

经济性看总投入和最终采用价值，不只看每秒单价。引用当前记录时区分报价、余额差、逐任务实扣、人民币与未知项；“关闭音频”“先480P后高清”“视频编辑保留动作”都必须有对应证据才可宣传为省钱。

## 7. 失败后按问题收敛

首次简单问题沿现有任务记录；反复出现或牵涉高成本取舍的未解问题才建立稳定ID，跨镜号和版本累计尝试。一次付费失败后，下一次之前必须说清：原来假设是什么、得到什么新证据、输入/表现方案改变什么、再花钱预计解决什么。同问题换名字不清零。若已有充分证据表明输入正确而失败来自随机性，可以提出保持输入的受控重抽，说明价值、次数上限并核对已有授权；不能为了满足流程乱改正确参数，也不能自动重跑。

| 判断 | 优先动作 |
| --- | --- |
| 主题/观看价值没成立 | 回到整片事件和观看结构，不批量生成局部补丁 |
| 图像或状态有矛盾 | 修实际输入，不能仅追加否定词 |
| 接镜或时长问题 | 先同时调整前后两侧剪辑，保留好表演 |
| 模型无法稳定实现核心动作 | 简化交互或改用另一种表达，再决定是否付费；不降低核心审美来假称完成 |
| 偏离提示但对整片有价值 | 作为创作偶然性评估，不因“不听话”自动重拍 |
| 没有新的可检验假设 | 停止该问题的付费循环，提出具体取舍 |

严重穿帮、核心人物或衣物突变是硬问题；光色差异、短暂遮挡等应结合镜头职责判断。重要选择集中交创作者，不把每个可自主剪辑的小差异都抛回去。

## 8. 检查和学习都以整片为单位

低成本输入检查 → 一次完整导出 → 原速带声审片 → 合并问题表。抽帧用于定位问题；解码、帧率、响度用于技术检查，均不能替代人的运动观感和听感。有新改动或未解风险才复查对应范围，不重复跑无变化的检查。

交付时区分完整候选、创作者定稿、实际发布和传播结果。“目前就这样”可以意味着停止改动，不能改写成全部问题消失。完成标准在开拍前约定，不能到最后才发现还缺声音、分辨率或准确结尾。

下部作品用少量指标检验方法：首次全片前因目标/参考矛盾而作废的生成、同问题付费次数与消耗、最终采用素材比例、从方案到整片的时间、首次整片后还剩多少核心问题。成本降低不能以减少必要镜头或丢掉核心表达为代价。

执行入口：[开工与制作卡模板](../templates/work/preproduction/production-readiness.md)、[问题表模板](../templates/work/production/problem-ledger.csv)。模板支持思考，不要求为每镜再写一份长文档。
