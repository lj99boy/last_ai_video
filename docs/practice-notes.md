## 2026-10-11 · 从《在伦敦》建立首片方案

来源：[作品考据](../works/0001-in-london/development/research.md)、[讨论稿](../works/0001-in-london/development/proposal-v0.1.md)、[试拍计划](../works/0001-in-london/production/test-plan.md)。

| 方法 | 本次依据 | 可复用范围与限制 |
| --- | --- | --- |
| 先问想获得什么体验，再决定情节 | 用户选择“先进入夜晚，感受氛围，再发现故事”，因此先建立空间再揭示人物行为 | 已实际用于本次方案组织；尚未证明成片有效 |
| 查画名时优先核对展签和展览资料 | 检索出现“巴黎餐厅”猜测，但展签/展览页命名为“在伦敦” | 考据经验；搜索结果流行的说法不自动成为事实 |
| 观察、解读、虚构分别记 | 银裙/红花可见；“离席”是动作解读；音乐/停留动机是改编 | 已落实到文档；每个新作品重新判断，不套统一寓意 |
| 先保留用户原始文件与指纹 | 上传照片为 8064×6048，带框、透视、反光，现已原样入本地素材目录 | 已验证原样复制；不把清理后的 AI 重构称为原画细节 |
| 先从一个动作及其回应建立短片 | 披肩动作提供“将走”的状态，收住动作可表现“等待” | 创作假设；需在静帧/视频中验证是否看得懂，不能只靠文案成立 |
| 画外声音可以延伸空间 | 本提案让音乐成为停步原因，不增设乐队镜头 | 制作假设；须经有声与静音观看比较，尚非实测省钱结论 |
| 表演难度和技术难度分开试 | S004 测情绪可读，S005 测双人/手/披肩连续性 | 对照设计；模型结果未取得，不能宣布优胜者 |
| 剪辑时长和付费生成时长分别记 | 分镜有 4/5/6 秒，但平台可能只提供固定时长 | 成本记录规则；最终按实际生成、重试和选用秒数计算 |

## 实际验证边界

已完成：来源身份交叉核对、原图保存和 SHA-256、六镜头时长计划、文档/表格结构检查。

待验证：观众能否理解故事、角色跨景别稳定性、油画材质运动、平台真实参考绑定与提示词处理、可用镜头成本、声音效果。

下次更新时用任务 ID、素材 ID、消耗与缺陷替换推测；旧结论被推翻时保留原因。

## 2026-10-11 · 新审美要求需要改变镜头与验收（随后被纠正）

用户明确“女性身段与亮片裙抓眼”后，不能只在提示词中增加“优雅、性感、摩登”三个词。本次将人物提前到开场，保留能看清身体线条的景别，把布料随动作的反光列为试拍对象，并同步调整验收与成本计划。见 [v0.2 提案](../works/0001-in-london/development/proposal-v0.2.md)。

这是已执行的方案修订方法，尚未成为生成效果经验。后续分别验证构图、姿态、材质和表演，避免用闪光滤镜误代替衣料质感，也避免把用户要求的性感弱化成仅仅端庄。

## 2026-10-11 · 区分视觉重点与出场顺序

v0.2 把“女性与裙装抓眼”推成“第一镜必须出现”，违背了用户想先进入餐厅氛围的顺序。用户明确纠正后，v0.3 恢复环境和专业服务的铺垫，将女主登场设为中段亮点。v0.2 的开场结论失效，不能继续当成可复用最佳实践。

可复用教训：新反馈可能只加强某个目标，不代表撤销原来的叙事结构。分别记录“什么最重要”“何时出现”“镜头如何表现”，修改时核对三者。结构变更必须连同分镜时码、角色参考、声音、测试对象与执行提示词一起更新；只追加决策日志不够。

本次是方案纠错经验，尚无生成效果实测。当前方案见 [v0.3](../works/0001-in-london/development/proposal-v0.3.md)。
