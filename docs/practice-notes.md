# 创作实践记录

记录能复用的方法及其证据。方案推导与实际生成经验分开；暂未产生首片模型实测结论。

## 实际验证边界

已完成：来源身份交叉核对、原图保存和 SHA-256、六镜头时长计划、文档/表格结构检查。

待验证：观众能否理解故事、角色跨景别稳定性、油画材质运动、平台真实参考绑定与提示词处理、可用镜头成本、声音效果。

下次更新时用任务 ID、素材 ID、消耗与缺陷替换推测；旧结论被推翻时保留原因。

## 2026-10-11 · 新审美要求需要改变镜头与验收（随后被纠正）

用户明确“女性身段与亮片裙抓眼”后，不能只在提示词中增加“优雅、性感、摩登”三个词。本次将人物提前到开场，保留能看清身体线条的景别，把布料随动作的反光列为试拍对象，并同步调整验收与成本计划。见 [v0.2 提案](../works/0001-in-london/development/proposal-v0.2.md)。

这是已执行的方案修订方法，尚未成为生成效果经验。后续分别验证构图、姿态、材质和表演，避免用闪光滤镜误代替衣料质感，也避免把用户要求的性感弱化成仅仅端庄。

## 2026-10-11 · 区分视觉重点与出场顺序

v0.2 把“女性与裙装抓眼”推成“第一镜必须出现”，违背了用户想先进入餐厅氛围的顺序。用户明确纠正后，v0.3 恢复环境和专业服务的铺垫，将女主登场设为中段亮点。v0.2 的开场结论失效，不能继续当成可复用最佳实践。

可复用教训：新反馈可能只加强某个目标，不代表撤销原来的叙事结构。分别记录“什么最重要”“何时出现”“镜头如何表现”，修改时核对三者。结构变更必须连同分镜时码、角色参考、声音、测试对象与执行提示词一起更新；只追加决策日志不够。

本次是方案纠错经验，尚无生成效果实测。当前方案见 [v0.3](../works/0001-in-london/development/proposal-v0.3.md)。

## 2026-10-11 · 从视觉张力到历史解释的证据边界

用户提出“传统餐厅与摩登女郎”的解读后，先拆成可见的色彩、材质、姿态对比，再查询同时期服饰实物。Met 1902 与 NGV 约1907 年的亮片晚装支持这种服饰具有时代合理性，但不证明画中人物有意挑战礼仪。

可复用方法：区分“看起来的反差”“当时是否罕见”“画家是否有意表达冲突”。创作可以采用一种读法，但不要把读法写成史实。也要区分原画的空间构图与改编视频安排的观看顺序。来源和本作品分析见 [考据补充](../works/0001-in-london/development/research.md)。

## 2026-10-11 · 第一张视觉探索图的实际经验

本次内置图片工具生成 V001。三格板能快速比较色调和观看顺序，但同一图包含多个阶段容易提前强化女主；把原画举手姿态直接带入“走入”描述，会使登场更像摆拍。此结论来自本次单张图，不代表所有模型的稳定规律。下一步拆成独立关键帧，环境镜头和登场镜头分别验收。

静态服务姿势不能证明放杯动作专业；静态银裙也不能证明反光随运动稳定。账户安装、OAuth 成功、工具可调用和生成效果需逐层验证。见 [V001 自检](../works/0001-in-london/production/V001-review.md)。

## 2026-10-11 · 先处理来源图，再延展画中世界

用户指出原始展厅照片有斜拍，且带框照片仅适用于回墙等艺术表现。此前视觉规范虽已写“正式参考不直接用展厅照片”，V001 执行仍直接绑定 R001，属于执行漏项。补做 R002 正视候选，去掉墙、框、展签，保留原片。AI 编辑存在局部重绘，必须记录而非称无损透视校正。

复用流程：来源原片存档 → 正视去框参考 → 对照验收 → 人物/场景参考 → 镜头关键帧 → 运动。原片是否作为回墙结尾另行创作决定，不能倒推成固定套路。见 [R002 自检](../works/0001-in-london/production/R002-review.md)。

## 2026-10-11 · 优先官方 CLI 或插件

插件授权成功与当前会话工具可调用不是一回事。当前会话缺少插件工具时，官方 CLI 1.1.3 能独立登录并操作同一画布。避免过早退回逐页点击。CLI 图像参考需要显式 modeType=image2image；缺失会校验失败。本次失败后先读回画布确认无残留节点，再纠正重试。上传资源只改名时 CLI 要求 params.model，当前版本无法仅改资源名；保留原名并记录用途，不给来源素材强塞生成模型。

## 2026-10-11 · 回到原画要从前段设计落点

首作回墙探索的推导：若最后要显露画框，前一个镜头就需准备人物姿态、相对站位、衣料和构图落点；声音可跨越显框以维持情绪。转场是否成功要用末段预演判断，不能只凭“很有艺术感”的文案。

当前为方案经验，尚无转场实测。生成片段负责表演，后期优先负责停帧、构图匹配和显框；不默认把五种变化塞进一个视频提示词。画作真源、AI参考和剧情关键帧分开，末端展示原作时回到真实来源。此结构是本片选择，不是所有名画视频必须采用的模板。

## 2026-10-11 · 先用现有静帧验证结尾剪辑

实际完成两版 6 秒回墙预演。原画与 AI 编辑参考存在细节和亮度差别；让回墙段使用同一张真实来源图片作透视和缩放，可以避免画框与原画继续被模型重绘，但不能自动解决前一镜的人物匹配。短叠化仍需逐帧检查；最终选择需在整片及声音中复验。

本轮一个技术故障也提示：遮罩参与 FFmpeg 滤镜时，像素格式协商可能改变画面色彩。v01 有非预期褪色，v02 显式指定彩色分支格式后修复。交付需同时查解码、关键时刻画面和完整观看，不能只看编码成功。具体素材和限制见 [预演记录](../works/0001-in-london/post/ending-preview-v02.md)。

## 2026-10-11 · 扩墙去黑边与独立关键帧

用户选定慢退显框后要求末端无黑边。采用画外扩墙、原作区域叠回真实来源的合成法；不能相信“保持原画不变”的生成提示就实现了像素保真。本轮生成扩展图改变了中心画面，并出现展签接缝，分别用原片覆盖和画外清理解决。输出需检查整段边缘和末帧，而非只看生成图。

独立镜头先生成餐厅，再把它与画作共同作为服务/登场参考，本轮三张候选的桌椅、通道、红灯明显更连贯。此为一次样本，不能宣称稳定保证。动作提示应服从实际起帧：杯底已触桌就测试松手收回，不能又要求向下放杯。静态步伐和银裙亮点仍需运动实测。

## 2026-10-11 · 首次视频动作实测

Kling 3.0 两个5秒样本：服务起帧杯底已触桌，提示松手收回后得到杯子留稳的候选；女主虽产生移动，但行走路径被前景桌椅遮挡。这说明“起帧全身可见”不足以保证移动后全身可见，需预留通道净空和停步位置。先把样片放进整体粗剪再判断重试，避免只盯一帧优化。

平台成功状态与审美/动作验收分开。本轮实际输出约5.042秒，粗剪按5秒取用；CLI没有费用字段，实际积分留未知，不能把会员积分生成写成免费。见 [两段实测](../works/0001-in-london/production/motion-test-review-v01.md)。

## 2026-10-11 · 技术试拍可用不等于作品好看

用户看过初版后反馈沉闷。固定机位和单动作利于模型验证，但把这些限制沿用到全片，可能造成景别、机位和情绪信息重复。声音尚未加入不能作为延后解决导演问题的理由。先对照已有素材与明确方法来源，分别检验声音和镜头组织，再付费补镜。

公开技能应先读具体内容再采用：本轮发现部分导演技能绑定流量钩子、CTA、链式延长和多次生成，和本片表达自由、后期控制及预算不一致。提取适用方法，不整体交出创作决策。见 [调研](directing-research-2026-10-11.md)和[检查表](directing-review.md)。这些改进尚未通过本片效果验证。

## 2026-10-12 · 从参考简介推进到实际画面与情感表演

此前内置浏览器播放失败后，只基于作者简介分析情绪。用户提醒外部 Chrome 可播放，实测确实成功；本轮继续按时间位置取样观察，确认真人电影式重构、面部反应、牵手与身体舒展、回原画的组织。浏览器播放到结尾不等于已经听辨音轨；当前仅做画面与可见字幕分析。

复用教训：技术可用、画面漂亮、情节成立、表演可信是不同问题。先问一个动作引出谁的反应、这个反应为何值得看，再决定景别与声音。回原画除了姿态匹配，也需要前段改变观众对画中人的感受。增加台词或笑容本身不保证动人，真人化也不是唯一解。

此处是分析与候选方法，尚无本片效果验证。见[参考片复核](reference-repin-screen-review-2026-10-12.md)与[首作v0.6讨论稿](../works/0001-in-london/development/emotional-story-v0.6.md)。所有新情节和画风改动均待共创选择，未覆盖执行方案，未消耗额外生成积分。

用户进一步纠正“学习而非抄袭，质感适合内容题材”。将参考采用的外观突出为我们的候选方向，容易混淆观察与推荐。今后先列本片需要表现的空间、材质、人物感受，再选择画面质感；保留有效创作原理，不把案例的风格、情绪曲线或人物关系当模板。氛围与感官体验也可以承载感动，不强制补一个戏剧转折。

## 2026-10-12 · 小主题不能冲淡用户原有立意

获准提出小主题后，Codex选择舒适停留，削弱了用户早先提出的传统餐厅与摩登女郎的张力。用户再次明确新旧冲突后，主题改为“她，让夜晚换了节奏”，用静稳空间对流动光泽、克制礼仪对自信身体来落实。主题应提炼用户的核心表达，不仅仅选择更安全、更温和的情绪。

生成已提交时收到新反馈，保留输出并标记撤回方向；不要因为结果漂亮就偷偷纳回主线。新主题同步所有实际执行文件，旧提示词显式标历史，避免只改决策日志而继续跑旧参数。此为协作流程经验，画面效果仍需预演验收。

## 2026-10-12 · 主题反差与故事变化分开检验

首作v0.7有传统空间与摩登人物的反差，但宾客回头后没有重要行为变化。复核时使用一个简单问题：删去这个反应镜头，后面是否基本一样？如果一样，它可能只增加观看气氛，未必承担故事推进。氛围作品并非必须有转折；只有当目标包括人物共鸣时，才需要进一步检验动作、选择及其后果。

学习案例分成来源事实、创作者经验、评论者分析和本片推论。不能因《La Luna》有个体选择，就把所有名画都改成成长故事；也不能因王家卫的形式富有情绪，就认为漂亮衣料加慢镜自然动人。本片优先测试现有披肩道具的微事件，是针对当前约束的创作假设，尚无效果验证。详见[研究与候选](../works/0001-in-london/development/story-assessment-v0.8.md)。

制作前用无解释字幕的动作顺序检查“发生了什么、谁主动决定、前后有何不同”，再加入声音检验完整体验。静态分镜不证明微表情能被视频模型可靠生成；简单的故事事件也可能包含困难的多人衣料交互，应分别估计叙事收益与生成成本。
