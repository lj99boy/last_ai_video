## 创意探索要提前到什么时候

首次制作一个尚无可靠表达方案的难场面时，先提出少量实质不同的处理；同一核心问题被再次指出时，立即重审原假设，不等用户再次要求“看看电影怎么拍”。这不是允许先付费失败两次的额度。

- 先判断问题在事件、机位、动作、观看顺序还是剪点。“管事转身就能逃”是事件前提；“4秒同时看冲锋、换斧、搬人”是观看任务过载。
- 按问题找对应场景。实际看过的片段、文字介绍、截图和官方建议分别标明；不能只贴片名。
- 采用参考时只留：**来源片段→看见的机制→本片哪一步改变→实际输入或剪辑如何落实→怎样观察是否有效**。
- “再自然一点”“再强调全速”不是新表现方案。可以换事件、起态、观察角度、镜头分工或剪点；固定机位本身并不错误。
- 用现有素材或简单排演先解除能解除的未知；白模不证明自然步态、承重和表演，不能让验证流程长度决定入片长度。
- 足以作决定便停止搜索。用户已选定且没有新矛盾的取舍不重复论证；实际输入和产物仍须审查。

## 每轮只记录一个短结论

直接追加到现有制作卡或问题表，不强制另建文件：

```text
本轮问题／阶段：
保留的主要行动与用户取舍：
相关经验ID与这次实际改变：
证据：哪个正文／素材／时码，以什么方式检查：
结论：已观察成立／未成立／尚未观察；下一步及停线条件：
```

“通过”必须带具体对象和判据：图片可用、配置读回、当前核价、动态可用、相邻剪辑可用、创作者采用分别说明。抽帧不能验速度感；ASR不能验表演；解码、响度和包相等不能验听感；指纹不能验汉语或叙事。缺少正常速度播放或人耳能力时，保留缺口，并集中交给创作者一次完整候选观看，不写成已通过。

**关键依赖不能一直等到最终审片：**影响是否重拍、后继输入或末态依赖的未验项，先审相关连续场面，再推进依赖它的制作；暂时无法验证就暂停依赖部分，集中说明需要判断的具体窗口。非关键的整片体验问题再合并到完整候选，不因此给每个小镜头新增审批或付费测试。

## 同一问题反复时怎样收敛

沿用[问题表](../templates/work/production/problem-ledger.csv)的稳定问题ID，不因镜号或版本变更清零。下一次付费前回答：原假设是什么、得到什么新证据、输入或表现法改了什么、预计看到什么结果。

先检查两侧剪辑和现有素材；不能靠追加否定词取消正确主动作。没有新假设则停止该问题的付费循环，提出具体取舍。若证据确实指向随机失败，可以提出有价值、有次数上限的同输入重抽；它仍不自动获得授权。有价值的偶然表演可以保留，不要求逐字服从。

## 怎样保存，才便于下次复用

| 信息 | 唯一维护位置 | 减少什么重复 |
| --- | --- | --- |
| 现在做什么、唯一候选与下一步 | 作品当前入口／制作卡 | 其他入口放指针，不把完整阶段对象复制到多个current文件 |
| 本轮输入、选用区间、实际结果 | 既有段落或问题记录 | 不为每名审查者再写一套同义总结 |
| 通用触发与检查 | 本页 | 不把某作品的造型、台词、固定时长变成通用规则 |
| 为什么得出经验、哪里仍有缺陷 | 对应作品复盘，使用稳定案例ID | 历史原件不重写；引用一次来源不算多次验证 |
| 按日期的原始积累 | [实践记录](practice-notes.md) | 作为依据按需读，不要求开工通读全部历史 |

新经验按“**触发症状／原判断／实际证据／这次修正／下次一项检查／不适用边界**”写入已有案例或作品复盘。只有新增条件、反例或执行方法才更新本页；同义重复只补来源。

现在不另建数据库或本地Skill：`AGENTS.md`、[工作流](workflow.md)与[制作卡](../templates/work/preproduction/production-readiness.md)已经是必经入口。以后跨仓库使用确有需要时，再封装只负责“选择阶段→定位案例→记录本轮改变”的薄Skill，规则正文仍只维护一份。

下一部作品检查：第一次完整有声串联是否更早、用户重复指出同一核心问题的次数、同问题付费尝试与实际采用区间、从方案到完整候选的时间。未记录的净扣和工时不补造，也不承诺节省比例。
