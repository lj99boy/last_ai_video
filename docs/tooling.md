## 成本

2026-10-10 官网页面实查：LibTV 标准版连续包月 66 元，1500 积分/月，次月续费 66 元。该订阅尚未购买。

页面对 1500 积分的单模型估算为 Kling 3.0 720p 约 188 秒、Seedance 2.0 720p 约 56 秒、Seedance 2.5 720p 约 33 秒；这些数量不能相加，实际参数、参考输入、活动和图片/重试消耗均影响结果。插件计费是否与页面一致仍待验证。

新增工具月度总预算不超过 100 元，不含已有 Codex 订阅。先使用一个平台，保留返工额度；不以年付折算价代替首月实际支出。不把已定预算当成已授权付款。

## 接入验证

1. 官方插件已安装。独立 Codex CLI 缺少可执行文件，改用桌面应用自带 CLI 成功安装，无需重装。OAuth 已返回登录成功；当前会话仍未加载工具，现由已验证可用的官方 LibTV CLI 继续执行。
2. 查询真实模型、参考参数、余额和报价，不猜测接口 ID。
3. 用代表镜头检查：参考是否正确绑定、模型是否符合选择、提示词是否被改写、能否只重做一个镜头。
4. 取回结果，核对文件并形成短剪辑，记录消耗与失败原因。

旧版 LibTV Agent 会话接口有用户报告提示词自动改写，不能直接推断新版插件也存在同样问题；将其作为验证项。

## 2026-10-11 接入实录

依据 [LibTV 官方说明](https://www.liblib.tv/plugin) 与 [官方 marketplace](https://github.com/liblib-ai/marketplace)，执行 marketplace add、plugin add libtv@libtv，安装版本 1.0.0。HTTP MCP 地址为 `https://mcp.liblib.tv/mcp`。使用原生 OAuth，不自行复制或保存令牌。

授权包含账户读取、项目读写、媒体上传、生成任务及导出。首次等待超时后已重新发起；不要保存带临时鉴权参数的 URL。当前会话工具列表尚未出现 LibTV 工具；授权后仍需验证插件刷新和实际工具调用，不能仅凭 mcp get 的 enabled 宣布可用。

已完成的概念图使用内置图片工具，与 LibTV 视频实测分开记录，见 [V001](../works/0001-in-london/production/V001-review.md)。
