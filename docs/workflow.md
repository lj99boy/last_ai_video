# 整体流程与分工

本页只管**谁在哪个阶段做什么**。每个阶段要问的问题见[制作经验入口](production-lessons.md)，创作细则见[画作到故事制作方法](painting-to-story-playbook.md)，资源与执行见[参考驱动的制作](reference-production.md)和[当前执行平台](execution-platform.md)。具体作品可以调整流程，不要求每一步做成繁重文档；每轮只在既有制作卡记录实际改变、观察证据和未验项。

场面持续性要求须同时进入镜表、实际参考职责和原速整片验收，不能只在讨论稿顶部加一句“更有活力”（依据见[实践记录](history/practice-notes.md#2026-10-16--主角动起来仍不等于整个场面活起来)）。

创作决策先于昂贵生成：先共同确定观看目的、改编范围、审美基准、交付和预算；再完成能指导整片剪辑的事件、动作与镜头设计。人物认可不代表材质或构图认可；静帧和空间预演不能证明自然动态。代表样片不是固定付费关卡，更不能先做一套测试再付费重做一套正式版。常规操作由 Codex 完成，主题、人物动机、结局和重大预算变化合并讨论。

片长、镜数、生成段数分别按内容和当前工具能力决定，不沿用首作的固定数字。减少付费试错不等于减少镜头；画幅和是否回到原画也由作品决定。新片用[一页制作卡](../templates/work/preproduction/production-readiness.md)汇总已有共识、制作建议和待决定项。

每个叙事节拍讲清故事作用、行动与回应、注意顺序和声音；每个实际制作段再讲清模式、源素材时长、参考职责、前后段的状态依赖和验收。节拍数、剪切数、精细图数与生成数分别决定。正式生成使用经过审看的参考组合；简单镜头可由独立人物／环境／风格等资料与文字设计完成，复杂接触或精确结尾构图才按需要补一张能看清人物和物件关系的图，或必要关键帧，不把“先有一张成品图”设为所有镜头的前提。正式输入只包含本次生成能获得的上下文，剪辑理由留在制作说明。

机位为人物行动和关系选择，高度、朝向、前景与遮挡都可变化；是否同侧由实际接镜是否清楚判断，既不要求全段同侧，也不强制跨轴。跨龄资料按当时年龄使用，图中的正脸、站姿、旧位置不自动变成表演约束。每段组合及其依据可用[参考计划模板](../templates/work/preproduction/reference-plan.md)集中记录。

需要表现持续生活或环境压力的场景，主戏外优先选一件可跨镜延续的次要事件；再写清风吹动哪些草木和衣物，人物接触、物体重量怎样影响道具。介绍场景的镜头要让观众看懂人物位置、路线和前后距离；近景可以只保留相关人物和可见的背景变化，不要求每镜每层都动。多张完整构图不得仅凭提示词中的先后顺序便视为可靠镜头序列；先检查实际景别、透视和开始状态是否冲突。对全片相关场景统一应用和审查，但不因此新增强制试拍、测试套图或付费关卡。

## 从展厅照片进入画中世界

来源是展厅拍摄照片时，保留原片作为来源档案；如果需要只含画面的正视基准，再校正相机斜拍，排除画框、展墙、展签和拍摄反光的干扰，保留画家原有的空间透视。校正相机视角不等于把画中空间拉平，也不意味着已知原作精确宽高比。已有清晰正视来源时可直接建立基准，无须重复处理。

按本片重点检查主体比例、姿态、关键服饰或道具、边缘完整性和光色。若用 AI 编辑，标为重构候选，不称无损还原；生成式补画不能作为原画细节考据。参考通过后，按镜头缺失信息选择人物、环境或其他资料，仅在必要时制作独立关键帧；为目标画幅设计取景或扩图，不直接拉伸原作。

带框照片可用于进入画作或结尾退回展墙等独立艺术表现，需要在故事和分镜中明确用途。不能因为有此素材就默认安排回墙结尾。原始照片、处理参考、创作关键帧分层保存并记录来源关系。

## 自动执行入口

优先官方插件或 CLI 完成模型查询、素材上传、参考连线、参数配置、生成与结果获取；网页主要用于用户观看和视觉验收。某入口不可用时先定位安装、登录、工具加载或接口能力，不直接把整条生产流程改成页面点击。CLI 与插件可能需要独立登录；各自验证。按段落组合选择多模态参考、首尾帧或本地剪辑，不因为某一入口已接通就把全片固定为一种模式。记录实际模型标识、参考节点／资源、用途与解析后参数，不能只记录平台展示名；官方能力、本机schema／dry-run、云端读回和实际生成效果分层记。

新组合先与先前版本比较：新增哪些媒体、传到哪个项目、增加什么云写入或消费、后续段落仍需满足哪些条件。已有明确许可直接复用；超出许可的增量才需确认。实际绑定、模式、时长、数量或模型改变后，旧报价不能继续作为这条请求的消费依据。执行前依次核实本地组合、保存读回与当前报价；保存成功、读回一致、允许扣费和动态通过是四件事。

返工先判断原因：故事不成立改事件与整片结构；输入冲突改真实参考；动作失败分析动作、绑定和模式；节奏或接镜不对先检查两侧剪辑。不按任务名清零：简单问题沿既有任务记录，反复或高成本问题才进入[问题表](../templates/work/production/problem-ledger.csv)，累计尝试、新证据和支出。偏离提示但有表达价值的效果可以保留；无新证据就不继续付费循环。若明确是随机失败，保持正确输入的受控重抽仍需具体价值、上限与已有授权。以含试错、升级和废弃素材的总投入及采用价值比较经济性，不用单价或一次成功宣布最优模型。
