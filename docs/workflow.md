# 整体流程与分工

初版整理：2026-10-11。具体作品可以调整流程，不要求每一步做成繁重文档。

| 阶段 | 创作者 | Codex | 产物 |
| --- | --- | --- | --- |
| 选画与解读 | 提供感受、问题与兴趣 | 查证背景，区分史实、解读与虚构 | brief.md |
| 主题与故事 | 决定表达方向与情绪 | 共创人物动机、转折与结尾，提出质疑 | story.md |
| 视觉与分镜 | 选择气质、构图与镜头表达 | 整理人物/场景参考，编写逐镜计划 | visual-bible.md、shots.csv |
| 静帧预演 | 看故事是否成立 | 生成候选静帧，按镜头时长组合预览 | 本地预演视频 |
| 代表镜头试拍 | 判断表演与情绪 | 对照模型、参考绑定、提示词变化与成本 | runs.csv |
| 正式生成 | 决定影响表达的变化 | 提交任务、检查连续性、保存各版本 | 素材及 manifest.csv |
| 剪辑与声音 | 看完整版本、调整节奏 | 粗剪、抽帧、字幕、声音组织与导出 | edit.csv、sound.md |
| 定稿归档 | 决定定稿与发布 | 整理交付、实际成本与复盘 | delivery/README.md |

创作决策先于昂贵生成：故事达成共识后再细化；人物与关键帧选定后再做运动；代表镜头通过后再制作其余镜头。常规操作由 Codex 完成，主题、人物动机、结局和重大预算变化回到讨论。

第一部作品建议以 20–30 秒、5–7 个镜头、一个主要场景、1–2 位人物试水，均为建议，尚非已批准脚本。画幅和是否回到原画由作品决定。

每个镜头至少讲清：故事作用、开始/结束状态、人物动作、景别、运镜、连续性要求、声音。分镜总览用于讨论，正式生成使用单独整理的参考与镜头图。

返工先判断原因：故事不成立改故事；脸或构图错误改静帧；动作失败改动作描述或模型；节奏不对先改剪辑。以“含重试的总消耗 / 可用秒数”比较经济性，不用一次成功或单价宣布最优模型。
