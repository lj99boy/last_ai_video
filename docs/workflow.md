# 整体流程与分工

初版整理：2026-10-11；2026-10-13按首作完整复盘修订。具体作品可以调整流程，不要求每一步做成繁重文档。执行细则见[画作到故事制作方法](painting-to-story-playbook.md)，事实依据见[首作复盘](../works/0001-in-london/delivery/retrospective-2026-10-13.md)。

创作决策先于昂贵生成：先共同确定观看目的、改编范围、审美基准、交付和预算；再完成能指导整片剪辑的事件、动作与镜头设计。人物认可不代表材质或构图认可；静帧和空间预演不能证明自然动态。代表样片不是固定付费关卡，更不能先做一套测试再付费重做一套正式版。常规操作由 Codex 完成，主题、人物动机、结局和重大预算变化合并讨论。

片长、镜数、生成段数分别按内容和当前工具能力决定，不沿用首作的固定数字。减少付费试错不等于减少镜头；画幅和是否回到原画也由作品决定。新片先填写[一页制作卡](../templates/work/preproduction/production-readiness.md)，不用让用户重复回答已有偏好或承担全部导演设计。

每个镜头至少讲清：故事作用、开始/结束状态、人物动作、景别、运镜、连续性要求、声音。分镜总览用于讨论，正式生成使用单独整理的参考与镜头图。

## 从展厅照片进入画中世界

原始展厅照片属于来源档案，不直接充当所有生成镜头的参考。先制作只含画面的正视基准，去掉相机斜拍、画框、展墙、展签和拍摄反光；保留画家原有的空间透视。校正相机视角不等于把餐厅内部透视拉平，也不意味着已知原作精确宽高比。

检查人物头身比、姿态、银裙等关键服饰、脸与手、前景器物、边缘完整性和光色。若用 AI 编辑，标为重构候选，不称无损还原；生成式补画不能作为原画细节考据。先通过参考检查，再制人物/环境参考与独立关键帧；构图取景或扩图放在这一阶段，不直接拉伸成 16:9。

带框照片可用于进入画作或结尾退回展墙等独立艺术表现，需要在故事和分镜中明确用途。不能因为有此素材就默认安排回墙结尾。原始照片、处理参考、创作关键帧分层保存并记录来源关系。

## 自动执行入口

优先官方插件或 CLI 完成模型查询、素材上传、参考连线、参数配置、生成与结果获取；网页主要用于用户观看和视觉验收。某入口不可用时先定位安装、登录、工具加载或接口能力，不直接把整条生产流程改成页面点击。CLI 与插件可能需要独立登录；各自验证。生成之前记录实际模型标识、参考节点与解析后的参数，不能只记录平台展示名。

返工先判断原因：故事不成立改事件与整片结构；输入冲突改真实参考；动作失败分析动作、绑定和模式；节奏或接镜不对先检查两侧剪辑。不按任务名清零：简单问题沿既有任务记录，反复或高成本问题才进入[问题表](../templates/work/production/problem-ledger.csv)，累计尝试、新证据和支出。偏离提示但有表达价值的效果可以保留；无新证据就不继续付费循环。若明确是随机失败，保持正确输入的受控重抽仍需具体价值、上限与已有授权。以含试错、升级和废弃素材的总投入及采用价值比较经济性，不用单价或一次成功宣布最优模型。
