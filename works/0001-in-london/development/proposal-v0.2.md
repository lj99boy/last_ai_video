# 第一版提案 v0.2：她是这个夜晚的第一眼

2026-10-11 · 审美方向已确认；故事与具体镜头待共创。承接 [v0.1](proposal-v0.1.md)，旧版保留供比较。

## 用户新增要求

时代的优雅与摩登并存。女性优雅、性感兼具的身段，以及银色亮片裙必须抓眼。保留“先进入夜晚、再发现故事”的体验方向。

## 对方案的实际改变

上一版先拍桌灯、杯沿，八秒后才让人物成为中心，会削弱这幅画最吸引人的部分。现在从第一镜就看见她，让观众通过她进入餐厅。环境与人物一起出现，故事稍后才显露。

审美主张：暖暗的餐厅里，她的银裙接住光；姿态修长、松弛、自信，抬手与微转身之间，肩颈、腰线和裙摆连成完整线条。灯光让材质发亮，动作让人有魅力。

## 当前六镜草案

| 镜号 / 时间 | 画面重心 | 作用 |
| --- | --- | --- |
| S001 / 0–4 秒 | 环境中的女子全身或近全身，银裙、红花、修长姿态与餐厅同框 | 第一眼就抓住人，同时进入那个夜晚 |
| S002 / 4–8 秒 | 保留脸和身体线条的四分之三身景；她沿抬手姿态整理发侧，轻转，裙面高光流动 | 让优雅与性感通过动作成立 |
| S003 / 8–13 秒 | 扩成双人近全身，发现身后男子持着披肩，似乎正准备离开 | 从视觉吸引进入事件 |
| S004 / 13–18 秒 | 面部与肩部近景，注意力转向画外音乐 | 让她表现主动选择，而非仅被欣赏 |
| S005 / 18–24 秒 | 同伴看见她停住，收住披肩动作 | A 故事仍是候选：有人理解她想多留片刻 |
| S006 / 24–30 秒 | 环境全身景，银裙与姿态仍在，夜晚继续 | 让人物魅力与情绪一起留下余韵 |

动作和音乐属于改编。后半段暂沿用“再听一小节”，尚未被用户选定；新的审美要求不等于已决定温柔、怅惘或浪漫的情节。

## 执行优先级

1. 先讨论/确认故事和画风，再做一张能成立的全身主视觉与一张同身份近景。她的身段、神情、服装和空间都达标后才扩展。
2. 首轮运动重点改为 S002：亮片质感随动作变化、身段不变形、油画或写实风格不漂移。
3. 第二类代表镜头仍为 S005 的人物回应与披肩连续性。先查账户报价，再决定是否做两模型四次对照；沿用原预算上限。
4. S004 面部表演在选定主力模型后补测，不把新增要求直接变成额外一轮付费横评。
