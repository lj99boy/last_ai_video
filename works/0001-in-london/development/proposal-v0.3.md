# 第一版提案 v0.3：一个值得走进去的夜晚

2026-10-11 · 历史基线；当前回墙探索见 [v0.4](proposal-v0.4.md)。用户确认的是叙事顺序与审美方向；下面的具体动作、时长、画风和收尾形式仍是建议。

## 修正

用户明确：先烘托室内/餐厅气氛与侍者的专业，再让女主曼妙登场，后续可接“这样的夜晚真美”的收尾。

v0.2 将“女主必须抓眼”误推成“女主必须最先出现”，现撤回。她的出场应是前面环境与服务铺垫后的亮点。“再听一小节”的离席故事不再作为当前默认主线，旧方案保留作历史。

## 观看体验

先想走进这家餐厅，再相信这里的每个细节都被妥帖照料，然后被她的登场吸引，最后觉得人物、灯光、音乐和服务共同组成了一个美好的夜晚。

侍者的专业通过动作的准确、轻稳和服务后的退让体现。他是这个空间有序运转的一部分，不设计夸张鞠躬或围观女主。

## 30 秒六镜草案

| 镜号 / 时间 | 画面与声音 | 作用 |
| --- | --- | --- |
| S001 / 0–4 秒 | 餐厅中广景，暖灯、白桌布、红色灯罩、交谈的人。缓慢进入，杯声与音乐先建立空间 | 让人想走进去；女主尚不成为注意中心 |
| S002 / 4–9 秒 | 侍者中近景，保持人物姿态可见，轻稳地将杯子放到桌面指定位置，然后收手退开；只有一声轻响 | 用具体、克制的动作表现专业，留下登场的空间 |
| S003 / 9–15 秒 | 女主从同一餐厅的桌间通道进入暖光，走一两步停下；全身或近全身，肩颈、腰线、裙摆连成流动的线 | 全片视觉亮点：曼妙、自信，银裙的光随步伐变化 |
| S004 / 15–20 秒 | 保留脸与连续身形的四分之三身景，抬手轻整发侧，微转；细密银色反光与红花清楚可见 | 从出场看到她的从容、优雅与性感 |
| S005 / 20–25 秒 | 近全身关系镜头，女主向同伴微微回应，姿态接近原画；背景服务与用餐继续 | 把她放回这个夜晚，建立人与人的温度；不强设恋爱关系 |
| S006 / 25–30 秒 | 镜头稍宽，人物、灯光、桌面与餐厅活动同框；乐句完成，环境声延续 | 让观众感到“这样的夜晚真美” |

S002 的服务动作、S003 的行走路线和人物回应是改编，不是画作中被考证的真实事件。通道只在必要范围内重构，不额外增加门厅/楼梯/街道场景。

## 收尾建议

优先用画面和声音留下“这样的夜晚真美”的感受。若希望文字点题，可试一句“这样的夜晚，真美。”作为备选；不自动加入旁白。先比较无文字版本，再决定是否需要点明。

不强加离别、秘密、旧日恋情或悲伤转折。此版可以是一段有起承转合的夜晚小品：环境铺垫→服务建立期待→女主登场→人物融入夜晚。

## 制作重点

先看三类关键帧：餐厅环境、侍者服务、女主全身；统一空间、光线和画风，再做六镜静帧预演。最重要的运动测试是 S002 手/杯/桌面的接触和 S003 步伐/身段/银裙材质。
