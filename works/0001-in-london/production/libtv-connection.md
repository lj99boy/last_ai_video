## 已发现的限制与处理

1. 仅设置模型与参考入边会默认为 text2image，校验拒绝；必须显式设置 modeType=image2image。失败后先读回画布，确认未留下节点，再重试。
2. 已上传资源单独改名遭 params.model 不能为空校验阻挡。保留 R001 原名，不对来源资源伪设模型；用途以本文和连线记录明确。
3. 模型 schema 返回名称与 supportModels 展示名可能不同。写入 model 用 CLI search 返回的 modelName，并记录真实 modelKey，不擅自推断背后的厂商品牌。
4. 目前读到的 schema 不含单次积分报价；生成尚未执行。参考图与画风需验收，具体消费范围需明确后再提交。
