## 作品

- **原画**：伊利亚·列宾，1880—1891，俄罗斯博物馆藏。片尾另注明展出地点“冬宫总参谋部”（创作者确认），与馆藏归属分开写。
- **观看目的**：让观众理解原画里这群人为什么会这样笑。
- **故事**：马尔科和谢苗受压迫时互相扶持，白天受罚、当晚逃离；被卢卡接纳。战斗中卢卡已带伤仍去救人，最终牺牲。多年以后，众人自由生活、互相打趣；收到要求臣服的来信后愤慨，一起用粗俗的幽默写回信，人群逐渐聚拢成原画的构图。
- **结构**：前段叙事约 87 秒；87–117 秒以文字呈现来信（左上）和回信节录（右下）；117–122.5 秒作品信息；最后 3 秒是原画。
- **史实与虚构**：列宾原画是史实；哥萨克回信是流传的传说，各传本文字不同；人物、经历和对白是本片虚构。
